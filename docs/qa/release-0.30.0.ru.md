# Проверки выпуска 0.30.0 · Linux amd64

Исходники: `8bcbad894d5516addb1544586226257fae12fa97`. Поставка ограничена Linux amd64 по новой команде владельца; прежние Windows-артефакты сохранены.

## Сборка и воспроизводимость

```sh
python3 scripts/build-release.py v0.30.0 --platform linux --source-ref 8bcbad894d5516addb1544586226257fae12fa97
python3 scripts/verify-asset-release.py v0.30.0
python3 scripts/verify-web-release.py v0.30.0
sha256sum -c downloads/SHA256SUMS
```

Собраны пять статических ELF amd64 с Go 1.26.0, `GOAMD64=v1`, `CGO_ENABLED=0`. Build manifest содержит тот же исходный commit для всех служб, `source_dirty=false`. Выпуск не содержит новых Windows-бинарников. Старые контрольные суммы сохранены, обновлены только общий индекс текущего пакета и записи новой поставки.

Проверены 283 графических ресурса и 127 файлов интерфейса. Два ZIP и все пять Linux-бинарников побайтно совпадают с ранее проверенной поставкой из рабочего черновика.

## Функциональные проверки

- Повторный `npm test`: 84 PASS, включая встроенную загрузку, ожидание eager-изображений и SVG-голограмм, повтор/отмену, вложенные исследования, категории администратора и потерю роли.
- Повторные race-проверки Web, webbundle, configuration, gamesignal и natscore: PASS, включая настоящий NATS 2.12.3; `go vet ./...`: PASS.
- Локальный полный набор Go: 178 корневых интеграционных тестов — 161 PASS, 17 опциональных SKIP; остальные пакеты прошли. Чувствительный к 200ms SQL-дедлайну набор повторно прошёл отдельно после transient heartbeat error при одновременной нагрузке четырёх локальных наборов.
- Реальные браузерные сценарии через Web и отдельную PostgreSQL 17.12: терминал, рынок/корабли/планировщик, исследования/колонии, редактор галактик, именование, уведомления, руководство, строительство, клавиатурный ввод, переходы и 70 секунд ходьбы без reconnect.
- Повторное открытие страницы: семь первоначальных PNG-передач и ноль повторных, Canvas остаётся читаемым. Политика immutable CDN проходит через Web.
- Native N5/N6: отдельные процессы с `-race`, остановка/возврат брокера и SQL-сверка. Для Web проверены инвалидация публичного каталога, TTL без NATS и reconnect.
- Совместный запуск пяти Linux-служб: все ready, авторизованный API через Web, версия из БД 0.30.0. Web и CDN запускались с TOML без `[database]`; корень Cosmic/CDN — 404, Web — 200. Тестовые процессы остановлены.

Рабочая PostgreSQL владельца и конфигурации действующих служб не использовались. Проверки проводились на локальных временных базах `*_test`; Windows 0.30.0 не поставляется.
