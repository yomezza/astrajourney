# Astra Journey — Руководство пилота / Original C

**Статус:** автономный frontend-прототип для просмотра и будущего согласованного внедрения. **Не является production-кодом.**

Это публикация **первоначального варианта C «База знаний пилота»** из первой сравнительной лаборатории A–E. После выбора владельцем этого стиля были исправлены два дефекта: сброс прокрутки при выборе статей и отсутствие движущейся SVG-проекции в статьях о космических объектах. Пять позднейших вариаций C здесь **намеренно не опубликованы**.

## Как посмотреть

1. Скачайте/распакуйте каталог и откройте `index.html` в современном браузере. HTML, JS, CSS и статьи находятся рядом; CDN, `fetch`, игровые API, PostgreSQL, Go, NATS и сборка не нужны.
2. Проверьте поиск, категории, «Все темы / Избранное / Недавние», связанные статьи и «Предыдущая / Следующая».
3. Переключите категорию **«Космические объекты»**, откройте «Садовый мир» или «Звезда»: должна появиться анимированная SVG-проекция, вращающаяся вокруг вертикальной оси с полным циклом в 360°.
4. Включите «65 тем», прокрутите список вниз и выберите разные статьи. **Список остаётся на том же месте**. То же относится к чтению и работе с избранным. Переключите размеры 420×580, 810×550, 960×580 и 760×340.
5. Демонстрационное окно можно перетаскивать за заголовок и менять размер за нижний правый угол; это **не** production `Modules`.

При ограничении браузером `file://` можно из папки родительского каталога выполнить `python3 -m http.server 8000` и открыть `http://localhost:8000/original-c/`; сервер лишь отдаёт локальные файлы.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Однооконная лаборатория с **единственным** дизайном Original C |
| `styles.css` | Стили, выделенные для исходной компоновки C; цвета, рамки и компактность терминала |
| `app.js` | Общая библиотека статей, табы, категории, поиск, избранное, история, прокрутка, локальное окно |
| `hologram.js` | Новые процедурные inline-SVG проекции 10 объектов; полный непрерывный 3D-yaw 360° |
| `fixtures.js` | Локальные 25 статей из предыдущего прототипа, разделённые по происхождению |
| `STYLE_GUIDE.md` | **Визуальные токены, расположение, размеры, UI-паттерны, производственные референсы** |
| `FUNCTIONALITY.md` | Что было в production, что реализовано здесь и что лишь mock |
| `HANDOFF.md` | Пошаговая рекомендация разработчику по переносу выбранного варианта |
| `test_prototype.py` | Локальный браузерный регрессионный тест (при наличии Playwright) |

Проверенная палитра и источники: `internal/server/web/styles/tokens.css`, `internal/server/web/styles/chat.css`, `internal/server/web/features/notifications/index.js`, `internal/server/web/features/guide/index.js`, `internal/server/web/features/objects/presentation.js`, `internal/server/web/ui/windows.js`, `internal/server/web/features/shell/navigation.js` — см. подробности в [STYLE_GUIDE.md](STYLE_GUIDE.md).

**Важное:** SVG здесь представляют новые лёгкие векторные проекции, а **не скопированные production-файлы** `object-*.svg`. Для внедрения следует сохранить `objectHologram` и официальные SVG-ресурсы, отдельно исправляя их полный цикл вращения при необходимости. `hologram.js` служит понятным эталоном математически непрерывного поворота, а не готовой заменой графического пакета игры.

Все состояния (`favorites`, `recent`, выбранная статья) хранятся **только в памяти вкладки**; browser storage и игровые API не используются. Прототип не изменяет игру. Ни один из файлов сам по себе не должен размещаться под `internal/server/web/` без отдельного задания.
