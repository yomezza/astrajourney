# Cosmosimulator 0.24.4 · TOML для трёх серверных служб

Cosmic, Planet и Chat теперь могут получать настройки из TOML. Путь задаётся
переменной `CONFIG_FILE`. Если она не задана или пуста, сохраняется прежний запуск
через переменные окружения. При выборе файла он становится единственным
источником настроек приложения; отсутствующие параметры используют встроенные
defaults, обязательные значения проверяются при старте.

Общий загрузчик используется во всех службах, gateway, статусах, bootstrap
администратора и командах Chat `--maintain`/`--grant-runtime`. Секции:
`database`, `cosmos`, `admin`, `planet`, `chat`. Поддерживаются булевы значения,
числа, массивы Origin/сетей и строки длительностей. Можно использовать отдельные
файлы или общий TOML с независимыми адресами соединений каждой службы.

Опечатки, неверные типы, повреждённый или недоступный файл останавливают запуск;
скрытого переключения на окружение нет. В ошибках TOML выводится позиция без
значений реквизитов. Относительные пути журналов считаются от папки TOML.
Изменения файла применяются после перезапуска службы.

Готовые примеры находятся в `configs/*.example.toml`, полная инструкция и
соответствие переменных — в `docs/configuration.ru.md`. В статусе отключённого
чата показаны варианты включения для обоих режимов.

Проверены выбор источника, изоляция от старых переменных, ошибки и отсутствие
секретов в сообщениях парсера, относительные пути, независимые адреса служб,
примеры и существующие валидаторы. Подготовлены три Windows EXE, предыдущие
версии сохранены. Миграций БД нет.
