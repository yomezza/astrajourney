# Astra Journey Web 0.31.1 — стабильный рынок модулей

Только **Web, Linux amd64**, поверх Cosmic 0.31.0. Другие службы,
схема БД и пак графики не меняются.

Исправлено постоянное исчезновение и повторное появление содержимого
«Рынок → Модули корабля». Раньше каждый фоновый опрос очищал окно до получения
ответа API. Теперь открытая вкладка сохраняется на время запроса. Цены,
остатки и возможность покупки обновляются на существующих карточках;
фильтры, вкладки, фокус и положение прокрутки не сбрасываются.
При смене станции или корабля покупка использует актуальные данные.

Замените только Web-бинарник и задайте в `[web]`:

```toml
release_tag = 'v0.31.1'
sync_enabled = true
```

Перезапустите Web, дождитесь активации пакета и обновите страницу.
Cosmic остаётся на 0.31.0, Planet/Chat/CDN — на 0.30.3.
Общая версия игры в БД остаётся 0.31.0: это отдельное исправление Web.
Релиз не меняет общий GitHub Latest, используемый для графики CDN.

Проверено локально с синтетическими ответами: задержанный фоновый запрос,
сохранение карточек/фильтров/фокуса, изменение остатка и блокировка покупки,
фильтрация по классу; сценарий перетаскивания оснащения и открытия рынка.
Полные и нагрузочные прогоны не запускались; обращения к рабочей БД не было.
