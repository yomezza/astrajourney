# Галактики: создание, ресурсы, интерфейс и 5–50 000 систем

Задание: [прямые запросы владельца](../../prompts/backend/002-galaxy-editor-and-limits/prompt.md).
Версия: **Cosmic 0.24.16**. Planet и Chat остаются **0.24.14**.
Ветка: `fix/galaxy-creation-and-editor`, основание — `main` на `2c46ccf`.

## Проблемы и исправления

| Проблема | Причина | Решение |
| --- | --- | --- |
| Ошибка «Укажите распространённость каждого ресурса» после заполнения всех полей | Общий каталог трюма содержит `colony_core`, но контракт настроек генерации — только ключи из `GalaxySettings.resource_weights`. Форма добавляла лишний ключ, и проверка количества ресурсов отклоняла запрос | Поля месторождений ограничены ключами настроек, полученных от сервера. Технологии туда не попадают. Скрытые коэффициенты сохраняются; серверная проверка полного набора ресурсов не ослаблена |
| Потеря введённых данных при переключении каталога | Повторная загрузка заменяла форму серверными значениями | Черновики сохраняют название, количество, форму, зерно и коэффициенты; есть отмена создания и сброс правок. При выходе из аккаунта черновики очищаются |
| Непонятная ошибка в свёрнутой группе ресурсов | Обязательное поле могло быть скрыто в `details` или поиском | Перед запросом раскрывается нужная группа, снимается фильтр, выделяется первое некорректное поле; ошибка показывается внутри панели |
| Нельзя задать 5 или 50 000 звёзд | В форме и сервере действовал диапазон 50–10 000 и общий предел 50 000 | Диапазон новой галактики — **5–50 000**. Существующую галактику можно расширять до 50 000, уменьшение по-прежнему запрещено |
| Прежний общий предел мешал одной галактике на 50 000 при уже существующих других | Лимит относился ко всей вселенной | Защитный общий предел согласован с существующим максимумом 24 галактики: 24 × 50 000 глобальных записей систем. Это арифметический предел, а не результат нагрузочного испытания такого мира |
| Большая генерация прерывалась по времени | Дублирующие и попарные вычисления; общий контекст API 12 секунд и HTTP-запись 15 секунд | Убрана генерация неиспользуемой сети, поиск соседей индексирован. Только POST предпросмотра/применения галактик получают ограниченный бюджет 2 минуты и соответствующий срок записи HTTP. Аутентификация остаётся ограничена 12 секундами; проверки роли сохранены |

## Внешний вид

- Компактный каталог галактик с символами формы, числом систем и состоянием черновика.
- Сводные показатели выбранной галактики и отдельный заголовок редактора.
- Вкладки **«Параметры» / «Предпросмотр»**; карта больше не находится под всей формой.
- Плитки выбора спиральной, кольцевой, эллиптической и нерегулярной формы.
- Компактные группы параметров, поиск сырья и возврат коэффициентов к 100%.
- Отдельная строка состояния, подсветка ошибочного поля и постоянная нижняя панель действий.
- На предпросмотре карта идёт первой; сравнение показателей и ресурсов раскрывается в «Сводке изменений».
- После изменения параметров старый предпросмотр нельзя применить. Ответ 409 также требует нового предпросмотра.
- Адаптация к размеру окна; RU/EN-подписи. CSS ограничен `.galaxy-admin`.

Снимки тестового мира: [предпросмотр](../../../docs/design/galaxy-admin-v0.24.16/preview.png), [узкое окно](../../../docs/design/galaxy-admin-v0.24.16/narrow.png).

## Генерация и совместимость

`Generate` сохраняет прежний результат для обычных вызовов. Управляемые галактики пропускают только построение неиспользуемой промежуточной сети: звёздные метаданные и последовательность генератора не меняются.

Для размещения новых звёзд используется пространственная сетка с тем же порогом выбора расстояния 32. Галактики до 10 000 систем сохраняют прежний алгоритм коридоров. Для больших применяется минимальный связующий лес с пространственным поиском, ближайшие дополнительные связи и межрукавные мосты. Отрицательные регионы остаются изолированными; защищённые действующие маршруты добавляются прежним способом.

Новых API, полей запросов, SQL-миграций, зависимостей и изменений конфигурации нет. Производственные данные, координаты существующих систем, склады и маршруты тестами не менялись. Изменения относятся к Cosmic; отдельные Planet/Chat не пересобираются.

## Проверки и фактические результаты

Использованы собственные временные схемы в отдельной PostgreSQL `_test` и Chromium на Linux. API в браузере не подменялись.

- `TestGalaxyEditorBrowser` — реальное заполнение формы, корректные ключи ресурсов без `colony_core`, 0% железа, сохранение черновика, аннулирование старого предпросмотра, раскрытие ошибочного поля, одно применение и создание кольцевой галактики. Проверены обычное/узкое окно и отсутствие ошибок JS/HTTP. Сценарий добавлен в существующий CI UI contracts.
- `TestCreateGalaxySizeBoundaries` — реальные HTTP-запросы к серверу с `WriteTimeout=15s`, создание **5 и 50 000** звёзд при наличии других галактик; 4 и 50 001 отклоняются. На этом стенде полный цикл предпросмотр + применение 50 000 занял **около 43 секунд**. Это измерение конкретного тестового окружения, не гарантия скорости другой машины.
- `TestManagedGalaxyPreviewAndApply`, `TestCreateGalaxiesAndPortals070` — пройдены: расширение, четыре формы, сохранение старых координат/имущества/маршрутов, защита предпросмотра, права и переходы через портал.
- `go test ./...` без `TEST_DATABASE_URL` — пройден; сценарии, которым нужна БД, в этом запуске пропущены. Реальные проверки БД перечислены выше.
- Новые проверки генератора: 50 000 систем, валидность и длины рёбер, изоляция, совпадение стоимости связующего леса с прежним алгоритмом, детерминированность, совпадающие координаты и граничное расстояние, сохранение метаданных при пропуске промежуточной сети.
- Проверки границ размера и области увеличенного тайм-аута — пройдены. Остальные операции API сохраняют прежний срок.
- `node --test architecture.test.mjs` — пройден: граф ES-модулей, отсутствие неявных глобальных имён.

Работа Windows-процесса на Windows, максимальная вселенная из 24 крупных галактик и многопользовательская нагрузка одновременно с большой генерацией не испытывались. Сборки Windows amd64 и Linux amd64 создаются из зафиксированного исходного коммита; сведения о подтверждённой публикации приведены ниже.
