# MATRIX × STUDIO 2.0 — контекстная модульная система

Дата согласования: 2026-11-28. Статус: продуктовая концепция владельца; документация не является утверждением о наличии функций в production. Ветка документации: docs/matrix-studio-v2-module-system. Базовый main: 60f2fcd4846595210425b9a2d646e59bbeaab26c.

## Цель
Развить действующий MATRIX × STUDIO из набора сводок в полноценный персональный командный терминал: единые семейства игровых инструментов, независимые экземпляры и функциональные подвиды, определяемые задачей и контекстом, а не внешним видом. Референс — APEX Prosperous Universe (экраны, плитки, временные окна, инструменты с аргументами), но без обязательного ввода команд, кодов и чрезмерной сложности. Сохранить компактность, привычную палитру MATRIX, текущую игровую механику и русскоязычный интерфейс.

## Объём первого этапа
M001.01, M002.01–03, M003.01–02. Остальные подвиды и семейства — будущие спецификации; не реализовывать в рамках текущего задания. Не проектировать межмодульные события, связи, drag & drop между экземплярами и цепочки их взаимодействия. Разрешение контекста через игровые данные не является межмодульным взаимодействием.

## Границы
Не переписывать игру целиком. Сохранить существующие механики, доступ к старым инструментам до их поэтапной замены, Planet Mode, старый production-стиль и функциональность Chat и Notifications, независимые глобальные экземпляры связи. Не вводить дополнительную экономическую службу в рамках этой задачи (она планируется отдельно). Новые продуктовые решения, не согласованные владельцем, перечислены в DECISIONS.md. Технические примеры — предложения для аудита и согласования разработчиками, не существующие API.
