Полный трюм и перемещение — M002; маршрут, стыковка и посадка — M003; добыча M005; сканирование M006; автоматизация M008; покупка/продажа кораблей M015. Не дублировать управление этими процессами.

## M001.01
S01 осмотр; S02 сравнение характеристик; S03 запас топлива и заправка; S04 просмотр/установка/снятие оборудования; S05 переименование; S06 местоположение; S07 деятельность.
- Обзор: имя и ID, корпус/роль, состояние, система и точная доступная позиция, топливо/ёмкость, заполненность трюма, текущая деятельность, изображение при достаточном размере, заправка внутри модуля. Переименование доступно в этом семействе.
- Характеристики: базовые параметры корпуса и фактические с учётом оснащения, реальные единицы/данные сервера, не выдумывать скорость или ёмкости.
- Оснащение: гибрид (изображение корабля + список слотов/оборудования при достаточном размере, компактный список при уменьшении); совместимость, установленные/свободные слоты, доступное оборудование, установка/снятие по реальным правилам. Покупка/продажа оборудования — сверить существующую механику, не создавать новый рынок. Общий UI списка, а не дублирование логики. Сохранить выбранный раздел для каждого экземпляра.

## Данные и действия
Backend проверяет владение ship_id и фактическое состояние (станция/космос/перелёт/добыча/исследование/посадка), предоставляет базовые и эффективные характеристики, слоты и доступные команды. Заправка — компактная форма количества, стоимость при платной операции, ограничения и подтверждение при необходимости; если действующий API заправляет только фиксированным способом, согласовать минимальное расширение, не имитировать частичную заправку. Установка/снятие, переименование, заправка адресованы явному ship_id; не менять активный корабль. Сбор топлива оборудованием — сохранить существующую доступность, не расширять правила. Ошибки и ограничения (нет топлива/денег/слота/доступа, занят, parked) показывать из авторитетного контракта. При недоступном корабле не подставлять другой.

## Приёмка
Два экземпляра с A/B, один follows workspace, другой fixed; смена workspace не меняет B, действия на B не меняют A. Смена размера не меняет подвид/раздел, сохранение раздела после F5. Заправка/оснащение/переименование работают с правильным ID без select_ship; отказ по чужому ID, несовместимому оборудованию, недостатку средств, изменению состояния. На узком размере список оснащения остаётся доступен. Чужой/спецификация не доступны в постоянном каталоге первого этапа.
