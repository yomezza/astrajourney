# Astra Journey 0.24.15 — исследования и колонии

Согласованные интерфейсы из frontend-демосреды доведены до рабочего Cosmic с настоящими игровыми данными.

- В «Исследованиях» можно выбрать систему из каталога: слева меняются её голограмма, сведения и действия. Текущая система корабля закреплена первой.
- Поиск, источник, страница и выбор сохраняются при возврате из «Подробнее». Фильтр источника компактный, без отдельного поиска.
- «Подробнее» корректно показывает реальные строковые ID объектов; исправлены конфликт шапки с основной страницей и закрытие всего окна по Escape при открытой подсказке.
- В «Колониях» сохранён двухколоночный каталог. Сведения о планетах обновляются после исследования; поздний ответ не подменяет актуальный. Действуют прежние операции проектов, поверхности, высадки и возвратов.
- Исправлено открытие закрытой карты поверхности при смене языка. Прокрутка остаётся внутри модульных окон; оформление адаптируется к размеру окна.

Новые игровые API и миграции БД не требуются. Скрытые объекты по-прежнему скрывает сервер.

**Обновляется только Cosmic**: Windows amd64 и Linux amd64. Planet и Chat используйте из версии **0.24.14**, прежний конфигурационный файл сохраняется.

Проверены настоящие API и PostgreSQL в отдельной тестовой схеме, браузерные сценарии исследований/колоний, права и возвраты, высадка двух игроков, RU/EN и узкое окно. Windows-приложение на Windows не запускалось.
