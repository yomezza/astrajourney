# Astra Journey 0.25.1 — исправление запуска Cosmic

- Убран общий лимит 15 секунд, который обрывал миграции и загрузку большого мира. По умолчанию инициализация получает 5 минут; параметр `[cosmos].startup_timeout = '5m'` или `COSMOS_STARTUP_TIMEOUT` в режиме окружения позволяет изменить срок. Подключение PostgreSQL отдельно ограничено 10 секундами.
- Синхронизация реестра открытий больше не перезаписывает неизменившиеся объекты. Исторические сведения при заполнении обрабатываются группами, вместо повторных поисков для каждого объекта.
- В журнале виден этап запуска: ожидание блокировок, миграции, реестр открытий и завершение. Ошибка содержит срок инициализации.

Обновляется только **Cosmic**, Windows/Linux amd64. Planet остаётся **0.25.0**, Chat — **0.24.14**. Новых миграций нет; прежний config.toml подходит без изменений. Замените Cosmic и перезапустите службу. При необходимости добавьте `startup_timeout` в уже существующую секцию `[cosmos]`.

Адресно проверены чтение TOML/примеров и реестр открытий в отдельной PostgreSQL: первичное заполнение, legacy, права именования и отсутствие повторной записи неизменённых объектов. Полный набор и браузерные проверки для этого исправления не запускались. Рабочая БД пользователя недоступна: при сохранении ошибки новый журнал покажет, на каком этапе она возникает.

Замена текстур и WASD в это исправление не входят по уточнению владельца.
