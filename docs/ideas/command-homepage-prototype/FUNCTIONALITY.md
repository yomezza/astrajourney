## Чего нет и почему

Поскольку это автономная демонстрация, не воспроизведены: настоящие игровые запросы, авторизация, права на действия, сохранение Preferences, серверные уведомления, реальный Chat Service, флаги корпораций и весь набор окон/вкладок производства. Для тестирования компоновки не нужно имитировать игровую бизнес-логику. Кнопки внутри макетных окон честно выводят предупреждение об имитации.

**Примечание о рабочих пространствах:** в прочитанных production-файлах подтверждён существующий менеджер окон `Modules`. Отдельный эксперимент с несколькими пользовательскими рабочими пространствами существует в `scripts/frontend-generation/mock/pilot-terminal/`; не следует принимать этот эксперимент за уже внедрённую production-функциональность.
