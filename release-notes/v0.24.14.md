# Astra Journey 0.24.14 — NATS в статусе служб

В административном окне «Статус служб» у Cosmic, Planet и Chat добавлен
отдельный тег состояния NATS: подключён, нет соединения, подключение,
отключён в настройках, не используется режимом чата или нет данных.
Статус обновляется вместе с карточками каждые 5 секунд и независим от готовности игры.
Для Chat отображается текущий dispatcher mode; в legacy/A1/A2 указано, что
NATS не используется, даже если профиль включён. Для работы через NATS нужен b1.

Снимок состояния не содержит адресов брокера, credentials, пользовательских
данных или содержимого сигналов. Старые службы без нового поля показываются
как «Нет данных». Для полной информации обновить все три приложения.

Добавлены проверки состояний и native -race сценарий: три службы подключены,
администратор видит три connected, после остановки брокера три disconnected,
игровые SQL операции продолжают работать. Старые конфиги совместимы.
Windows/Linux amd64 сборки всех трёх служб находятся в downloads и релизе.
