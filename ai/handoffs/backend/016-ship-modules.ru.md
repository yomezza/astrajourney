## Реализация

- `internal/server/schema310.sql`, `fleet/modules.go`, `terminal/modules.go`:
  каталог и бюджеты корпусов, экземпляры со снимком характеристик JSONB,
  запасы станций; транзакционные покупка/установка/снятие/продажа/сбор топлива.
  Миграция источника явно входит в поручение владельца о хранении в БД.
- Отдельные экземпляры вместо массива оснащения в JSONB корабля позволяют
  сохранять ID, собственную цену и состояние трюм/установлен. Ограничения,
  индексы и FK; владелец/корабль проверяются сервером. Платёж и остаток атомарны.
- Добытчики C/B/A/S четырёх подтипов, расширители только C, сканеры C/B/A/S,
  топливозаборники C/A/S, ускорители перехода C/B/A/S — всего 32 варианта.
  Для ресурса автоматически выбирается лучший установленный добытчик.
- В цену корпуса привязан начальный размер оснащения; DB-лимиты показываются
  в API и верфях. Характеристики участвуют в добыче, планировщике,
  исследованиях, переходах и проверках вместимости всех путей пополнения груза.
- Бесплатные стартовые модули не выдаются повторно после снятия/продажи.
  Прежняя вместимость и содержимое трюма сохраняются. Mining B — +1 к добыче.
- `web/features/outfitting`, `markets/modules.js`, `core/ship-capacity.js`:
  отдельное окно, карточки, установка/снятие кликом или drag-and-drop,
  модульный рынок с фильтрами и станциями только текущей галактики.
  Фоновые обновления тихие; асинхронный результат не заменяет активный drag.
- `web/index.html` больше не загружает `console.css`, убран body-класс.
  `web/ui/windows.js` восстановлен из v0.30.4. Разметка оболочки соответствует
  прежней; новое оборудование имеет отдельный CSS. Рендерер, стили и действия
  обеих карт не откатывались. Исторический console.css не удалён.
- Cosmic и Web имеют версию 0.31.0. Planet, Chat, CDN — 0.30.3.
  Миграция 310 однократно меняет общую версию игры в БД.
- Сборщик и release workflow поддерживают выбранные службы по manifest;
  для Cosmic+Web не собирается/публикуется графика и не меняется CDN index.
  Частичный релиз не занимает GitHub Latest, нужный CDN для полного пакета.

## Ограничения и эксплуатация

[Механика, таблицы, настройка и обновление](../../../docs/operations/ship-modules.ru.md).
Каталог редактируется через БД; отдельной админ-формы нет. Добавлять варианты
существующих семейств можно без пересборки; новое поведение требует кода.
Экземпляры пока не участвуют в складских и межкорабельных переносах ресурсов.
Нет автоматического пополнения магазина. Сбор топлива вручную в открытом
космосе раз в 10s. Изменение шаблона не перебалансирует купленные экземпляры.

Порядок обновления: backup, остановка писателей на время миграции, Cosmic31,
затем прежние Planet/Chat и Web31 с явным release_tag. CDN пак прежний.
Старый Cosmic после миграции не использовать: он не учитывает модули.
Рекомендуемый следующий шаг владельцу — обновить Cosmic и Web своей установки.
