## Открытые вопросы и технические предложения
Дополнительные контексты workspace, предел/восстановление временных окон после F5, алгоритм плиточной компоновки, точный API/schema/migration, начальная раскладка при незавершённом M008, выбор таблицы по умолчанию, ограничения конкретных операций, правила derived у временного окна и поддержка будущих подвидов — уточнять с владельцем при необходимости. Ни один из этих пунктов не разрешает изменять правила игры. Сценарий определения подвида через purpose/binding/permissions, формат descriptor, физическая структура файлов и rollout — технические предложения, не утверждённые имена API/таблиц.
