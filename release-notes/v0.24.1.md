# Cosmosimulator 0.24.1 · исправление интерфейса чата по макету v13

Перепроверена интеграция по `docs/ideas/chat-service/15-frontend-prototype-handoff-v13.ru.md` и самому HTML-макету архитектора.

- Убрана лишняя верхняя полоса: у чата один заголовок с обычными drag/resize/focus из системы окон. При переносе на главную перемещается тот же заголовок и экземпляр чата, геометрия плавающего окна сохраняется.
- Пустая полоса ответа не занимает место. Предпросмотр появляется только после «Ответить» и полностью скрывается после отмены/отправки/смены раздела.
- Контекстное меню ЛКМ/ПКМ и вложенные папки оформлены как в v13: прямые углы, строки 21 px, минимум 120 px, соответствующие фон/рамка/отступы/подсветка. Выбор темы больше не зависит от того, где остался фокус; остальные меню терминала сохраняют свою тему.
- В избранном показаны папки и карточки заметок/копий. Перенос отмечает текущую папку, «Все» остаётся системным представлением; создание заметки открывает отдельную форму.
- Поиск раскрывается кнопкой в заголовке, элементы ввода компактнее, эмодзи находятся рядом с отправкой. Дополнительные настройки убраны из тесного заголовка. Списки пилотов больше не сжимают имена в узкие столбцы.
- Подсказки служб и прочтения используют оформление v13 через существующую систему tooltip; ошибки форм обводят поля красным.

Проверены параметры реального меню против CSS из HTML архитектора, работа ПКМ при фокусе снаружи чата, вложенные папки, показ/отмена ответа, перетаскивание, закрепление/возврат окна и связанные UI-контракты. Дополнительно пройден существующий Chromium-сценарий с реальными Go/PostgreSQL.

Обновлены Windows-сборки трёх служб; все предыдущие EXE сохранены. Новых миграций для этой поправки нет; markers Chat=1 и Planet=7 сохраняются. [Установка](../docs/chat-service/README.ru.md) · [разбор расхождений](../docs/chat-service/UI-REVIEW-0.24.1.ru.md).
