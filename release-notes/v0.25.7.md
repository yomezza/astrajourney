# Astra Journey 0.25.7 — ходьба через временные сбои сохранения

- В настоящем браузере воспроизведён оставшийся цикл: временный таймаут записи координат завершал WS с save_failed. Теперь подтверждённо откатившиеся сохранения повторяются в ограниченном окне, без нового соединения. Неизвестный результат COMMIT не повторяется вслепую.

- Исправлены недопустимые для браузерного WebSocket.close коды 1002/1008, вызывавшие исключение при ошибке протокола или замене контроллера.
- Проверено: 70 секунд реальной браузерной ходьбы через несколько checkpoint с намеренно медленной записью PostgreSQL; одна эпоха и отсутствие переподключений.
