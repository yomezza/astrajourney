# Cosmosimulator Planet + Chat 0.24.10 · N5

После успешного PostgreSQL COMMIT перехода сектора Planet опционально публикует
Core NATS `cosmos.v1.signal.planet.sector.changed`. Stable signal_id совпадает
с operation UUID; в payload только необходимые metadata. Сигнал отправляется
до RAM Join, поэтому его ошибка не скрывает уже подтверждённый переход.
Ошибки/отсутствие NATS не отменяют SQL и не останавливают Planet.

Chat B1 принимает outbox и новый Planet subject независимо. Адресный dirty set
перепроверяется прежними SQL session/lease/ScopeStamp/presence/fence проверками.
Payload не выдаёт права и не переносит старый сектор в текущее состояние.
Legacy/A1/A2/B1, scope polling и независимая сверка сохранены.

TLS/auth/dial cancellation переиспользуются через общий natscore. Planet имеет
собственный static login/password_file и строгий TOML/ENV профиль, default off.
Новая Planet SUB ошибка не отключает существующий Chat outbox; для быстрого
пути требуется согласованное дополнение серверных ACL.

Проверены P02-01—P02-10, отдельные нативные Planet/Chat процессы, реальные TLS
NATS/PG/WS, rollback, старые события, потеря публикации, отказ RAM Join,
перезапуски, отсутствие брокера и независимость Global/Private/Corporation.
[Полный отчёт, ограничения и подключение](https://github.com/yomezza/cosmosimulator/blob/main/docs/operations/nats-n5/README.ru.md).

В релизе только Planet EXE и Chat EXE; Cosmic остаётся 0.24.6. Windows cross-build
проверен, запуск служб владельца не выполнялся. Рабочие NATS/PostgreSQL/configs
не менялись; SQL миграций нет. Нагрузочных сравнений нет. N6 не начинался.
