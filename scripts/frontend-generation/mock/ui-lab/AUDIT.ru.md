# Аудит UI/UX: результаты и пределы готовности

Источник актуального кода — `internal/server/web/`. Исторические документы `docs/refactoring/ui/CATALOG.ru.md`, `components.md` и `duplications.md` содержат прежние пути, поэтому при внесении записи нужно проверять сегодняшние `ui/` и `features/`. Также изучены `docs/ideas/ui-element-registry/`, текущая `scripts/frontend-generation` и утверждённые модули v13. `ui-registry-scan.py` используется как дополнительный инструмент после подготовки оригинального web.

## Добавлено и воспроизведено

Действующие API: `UI.button`, `UI.menu`, `UI.picker`, `UI.choice`, `UI.field`, `UI.tabs`, `UI.table`, `UI.fold`, `UI.bar`, `UI.empty`, `UI.dirty`, `UI.confirm`, `UI.hologram`, `Modules`, `pager` и `cursorMore`. Используются настоящие программные объекты из original-web с вымышленными данными.

Компактное ККМ использует утверждённую плотность/цвета `.chat-context-menu` из `mock/chat-native.css`, а список «Источник» — `.studies-source-kkm` из `prototype/studies/styles.css`. JavaScript-поведение этих двух проб — **демонстрационный адаптер**, не сам контроллер чата/исследований. Стили и JS оригинальных модулей не переписаны.

Списки, панели, Canvas-карты, drag/drop и вспомогательные feature-элементы используют безопасные адаптеры. Canvas-демо читает **локальный** `/api/galaxy` и `/api/system`; кнопка открывает штатный галактический модуль. Встроенный демо-Canvas не заменяет движок `features/maps/galaxy.js`.

## Доработка 16 бывших pending: интерактивные стенды

Ранее найденные элементы теперь имеют renderer `advanced`, статус `adapter`
и отдельный файл `advanced.js`. Это интерактивные пробы, не полная замена
игрового процесса. Их исходные источники по-прежнему представлены в
`catalog.json`.

| Группа | Проверяемое действие |
|---|---|
| Planet scene / tree / rock / actor | Оригинальные PNG-объекты и `createSceneSprites`, исходный hit-test дерева/камня, движение персонажа с клавиатуры и стрелками |
| Terrain / texture gallery | Исходные `terrain` / `texture` / `materials`, переключение биомов, отказоустойчивый fallback для недоступных PNG |
| Map hit-testing | На вымышленных звёздах/рёбрах из `/api/galaxy`: hit radius, выделение и масштаб |
| Cursor history | `UI.table` и `cursorMore` с постраничным чтением локальных записей |
| Cargo transfer | Оригинальный `resourceTile` + проверка drag-token и пределов количества, локальные остатки |
| Galaxy delete preview | Блокирующие зависимости, подтверждение написанием названия и исходный `UI.confirm`; типизированный шаг — **предлагаемый безопасный адаптер**, не функциональность оригинального исходника |
| Benchmark | Исходный `benchmark-chart-row` и метрики p95/rps/errors на синтетических тестах |
| Corporation flag editor | Палитра из оригинала, три цвета, `paintFlag` и локальное сохранение |
| Service status/log | Исходные `service-card` и `service-status-tag` + добавленный синтетический журнал; в production-модуле есть статусы, не такой журнал |
| Two-phase form | Исходные `UI.field` и `UI.confirm`, предпросмотр diff, запрет применения после незапланированного изменения |
| Rich tooltip | Исходный `registerTooltip`, проверка focus/hover и отдельного tooltip host |
| Linked windows | Два настоящих окна `Modules`, переключаемая связь `Modules.link` и `Modules.adjacent` |

Асинхронные PNG/texture leases, обработчики и тестовые окна очищаются при
закрытии UI/UX и при смене категории. Не меняются реальные ресурсы, флот,
корпорации и состояние других игроков.

### Предел проверки

Для исходных планетарных функций используется *настоящий код рендерера*
с геометрией/высотами вымышленной поверхности. Go-сервис, collision authority,
учёт сетевых игроков, серверная оценка прав и реальные бизнес-мутации в стендах
отсутствуют. Публикация `adapter` не означает точную реализацию всех механик
production-окна.

## Найдено, но не является самостоятельным типом компонента

Декоративные SVG paths, вложенные span/иконки одной кнопки, числа в progress, каждый отдельный корабль/звезда/товар, фоновые таймеры hover. Для них отдельный тип в реестре не создаётся: при необходимости адресовать конкретную кнопку/корабль используют второй реестр применений и отдельные ключи экземпляров.

## Кандидаты на сравнение, НЕ объединённые

| Семейство | Механизмы и различия |
|---|---|
| Меню | `UI.menu`, ККМ чата, ККМ исследований; разная плотность, стили, submenu/keyboard policy |
| Списки выбора | `UI.picker`, `UI.choice` и native select; разные popup, search, favorites |
| Кнопки | `UI.button`, `.chat-icon` и навигационные кнопки; размеры, pending-state, hit-area |
| Вкладки | `UI.tabs` и `.chat-tabs`; плотность, aria, прокрутка |
| Подтверждения | `UI.confirm` и destructive admin/planet flows; разные полномочия и валидация |
| Таблицы и карточки | `UI.table` и feature-specific master-detail; разные данные и поведение |

Сходство CSS не означает одинаковую бизнес-семантику. Замена общего компонента возможна только после пользовательского утверждения.

## Проверка

`tests/test_ui_lab.py` проверяет каталог, имена, источники, ID, счетчики, семейства renderer и безопасную интеграцию; исходные файлы чата/исследований не меняются. Синтаксис JS проверен до публикации.

**Ограничение:** полноценный Chromium E2E всех 156 карточек с установленными 152 original-web файлами в этой среде не проводился. Перед объявлением production-паритета необходимо выполнить browser smoke на стороне демосреды (1440px, 390px, keyboard, hover/edge popup, resize, Console), затем усилить нужные адаптеры и повторно запустить `python ui-registry-scan.py`. Отсутствие `pending` означает наличие живых стендов, а не завершённый исходный UI-аудит.
