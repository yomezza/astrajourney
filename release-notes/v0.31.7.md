# Astra Journey 0.31.7 — приветствие при входе

После входа в терминал появляется окно «Немного о том, куда вы попали». В нём автор рассказывает о проекте, ранней стадии разработки и модуле «Предложить идею».

Галочка «Больше не показывать» сохраняется для аккаунта в текущем браузере. Без неё окно появляется после каждого входа через форму авторизации. Окно можно закрыть кнопкой «Продолжить» или клавишей Escape.

## Обновление веб-интерфейса

1. Скачайте файлы релиза в один каталог и выполните `sha256sum -c SHA256SUMS`.
2. Сохраните текущую ревизию из `/web/api/v1/health/ready`. Для ручной установки оставьте `sync_enabled = false` в секции `[web]`. Остановите службу Web.
3. Запустите действующий бинарник Web с тем же `CONFIG_FILE` и аргументом `--install-pack /путь/к/astra-journey-web-REVISION.zip`. Затем запустите Web штатно.
4. Сверьте `revision` в `/web/api/v1/health/ready` с `astra-journey-web.json`. Шапка терминала показывает версию Cosmic `v0.31.6`.

Для отката остановите Web, выполните `--activate <предыдущая-ревизия>` с тем же конфигом и снова запустите службу.
