# M003 — Навигация (navigation)

Статус: продуктовый паспорт согласован, 2026-11-28. Назначение — планирование, запуск и контроль перемещения конкретного корабля. Оба подвида первого этапа: плитки и плавающие окна, workspace/fixed собственный корабль. Подвид определяется задачей (межзвёздная/локальная), не размером и не текущим статусом полёта.

| ID | Variant | Задача |
| --- | --- | --- |
| M003.01 | navigation.interstellar | Межзвёздные маршруты |
| M003.02 | navigation.local | Перемещение внутри системы |

Границы: выбор назначения, расчёт маршрута/времени/топлива, запуск, контроль, отмена оставшегося маршрута, стыковка/отстыковка, орбита, посадка, портал, спасение — M003. Заправка M001; полноценное изучение мира M004; сканирование M006; автоматические цепочки M008; доставка M009. Управление персонажем на поверхности — Planet Mode. Портал/спасение — действия, не самостоятельные подвиды.

## M003.01
S01 выбор доступной системы; S02 маршрут через промежуточные точки (добавить/удалить/переставить, текущий Backend до 20 waypoints); S03 текущий переход, оставшиеся точки, прогресс/ETA, остаточный расход и доступное/зарезервированное топливо; S04 отмена оставшейся части маршрута; S09 переход через портал; S10 спасение.
Основное представление — **графическая схема маршрута** (выбор владельца Q04), адаптивная, с текущей позицией, переходами/точками/назначением и читаемыми подписями. Не заменять схему обычным списком; текстовые элементы редактирования и доступное описание допустимы, не отдельная карта. Использовать фактический маршрут/гиперлинии, а не выдуманную геометрию. Поиск по названиям доступных систем и личным закладкам без обязательного открытия карты. До запуска показать серверно согласованный расчёт времени/топлива, последствия и недоступность; при изменении условий пересчитать/перепроверить. Не обещать точный ETA при отсутствии достоверных данных. Не отменять уже начатый переход мгновенно: current cancel_route очищает оставшиеся waypoints/reserved_fuel, подтвердить фактические правила. Спасение с явным подтверждением, стоимостью и последствиями из Backend; портал — права, доступ и правила текущей игры.

## M003.02
S05 выбор объекта внутри текущей системы (станция, планета, месторождение и другие разрешённые объекты); S06 стыковка/отстыковка; S07 выход на орбиту; S08 посадка. Поиск и личные закладки. Показать текущую систему/позицию, цель, доступные режимы перемещения, расчёт времени/топлива если применимо, прогресс/прибытие. Схема локального маршрута при наличии данных, без имитации полноценной карты. При изменении системы обновить список допустимых объектов, не переиспользовать старую цель. Инициация посадки в навигации, после успешного перехода использовать действующий Planet Mode; не реализовывать управление персонажем здесь. Сохранить правила parked/landing и текущие ограничения.

## Backend
Сверить internal/navigation/commands.go (route, explore, cancel_route, rescue, portal_travel), portals.go, fleet/position.go, реальные move/landing и planner handlers; web/features/maps/galaxy.js, navigation/pickers.js. Не использовать explore как обычный route: он запускает исследование. Все запросы/команды адресуют явный ship_id, актуальные IDs системы/объекта/галактики, сервер проверяет ownership, available/idle, доступность пути, топливо, резервы, разрешения, актуальность назначения. Предпросмотр маршрута не запускает движение/исследование, сервер повторно валидирует при подтверждении. UI-черновик не равен серверному route; не редактировать активный маршрут тихо. Семантика редактирования активного маршрута — только разрешённые текущие операции, не новая механика. Не придумывать API, если нет необходимых данных, согласовать минимальное расширение.

## Приёмка
Два корабля A/B (включая fixed при другом workspace), параллельные схемы и команды, без select_ship. Маршрут с 1 и 20 точками, превышение лимита, повторные/недостижимые цели, недостаточное топливо, смена состояния между preview и start, отмена только разрешённой части. Поиск/закладки, стыковка/орбита/посадка, отказ чужого ID, портал и спасение с подтверждением. Уменьшение модуля сохраняет схему и доступ к действиям. Переключение пространства не запускает/прерывает маршрут. Временное окно сохраняет исходный корабль. Сверить ETA и расход с сервером, Planet Mode без регрессий.
