# Графика Astra Journey

Готовые игровые ресурсы находятся в `game/`: `space/ships`, `space/objects`,
`planet/pixelart-v1`, `ui/icons`, `ui/branding`. Они не входят в embed ни одной
службы. Исторические материалы и художественные исходники в `docs/design/`
остаются на прежнем месте.

Добавляйте графику в подходящий каталог, используйте имена ASCII без пробелов.
`game/aliases.json` связывает физический путь со стабильными логическими URL.
`legacy-aliases.json` фиксирует хеши прежних `?v=` URL: сборка не привязывает
старую версию к изменённым байтам.

После изменения:

```sh
go run ./cmd/astra-assets -out /tmp/astra-assets
go run ./cmd/astra-guide-assets
```

Первый инструмент готовит ZIP/манифест и обновляет компактные ссылки клиента и
HTML-иконок. Второй проверяет каталог встроенных иллюстраций руководства; сами
SVG по-прежнему остаются внешними файлами. При изменении pixel-art набора также
поддерживайте согласованность его manifest, atlas и farm-layout.json. Изменение
разметки спрайтов требует нового согласованного клиентского контракта.

Релизная сборка публикует подготовленный пакет в GitHub Releases. Установленная
CDN-служба забирает его автоматически. Копировать графику на игровой сервер по
одному файлу и вручную создавать каталоги не требуется.

[Установка, обновление, кэш и private media](../docs/operations/cdn.ru.md).
