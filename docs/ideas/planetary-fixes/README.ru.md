# Astra Journey — Planetary Fixes

**Статус:** идея согласована владельцем игры; реализация не запущена.

Тема: вместо отдельного перемещаемого окна `planet-visit` организовать переключение **космический терминал ↔ самостоятельный полноэкранный планетарный 2D-режим** в одной браузерной странице, с собственной HUD-оболочкой планеты. Переходы сопровождаются заставкой в стиле существующего «Подключение к серверу», а загрузка графики показывает группы и честный progress-bar.

Согласованное движение: **щёлкнуть объект → персонаж подходит к достижимой точке рядом**. Обычный возврат в космос — через настоящий посадочный модуль, без автоматического взлёта; аварийный recovery — отдельно. Космические окна скрываются с сохранением UX-состояния, чат доступен в обоих режимах, загрузка нужна также при смене сектора.
