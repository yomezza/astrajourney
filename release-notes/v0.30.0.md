# Astra Journey 0.30.0

Добавлена пятая Go-служба **AstraJourney Web**: браузерный интерфейс и публичный HTTP-шлюз вынесены из Cosmic. Новые сборки выпускаются **только для Linux amd64**; ранее опубликованные Windows- и Linux-файлы сохранены.

- Окна модулей используют общий внутренний загрузчик в стиле стартовой страницы. Он ждёт данные, eager-изображения, SVG-голограммы и обязательную подготовку Canvas. Есть повтор после ошибки, ограничение ожидания и отмена при закрытии. Подключены вложенные исследования, поверхность и окна колонизации; новым модулям доступен тот же контракт готовности.
- Планировщик получил сводку выполняющихся/ожидающих/приостановленных задач, фильтр очереди и обновлённые блоки создания и выполнения задач.
- Панель администратора открывается отдельным модулем с категориями «Службы и диагностика», «Игровой мир», «Игроки и контент», «История изменений».
- «Верфи» убраны из списка модулей; покупка кораблей сохранена во вкладке рынка.
- Добавлены «Корпорация-основатель 03» и «Корпорация-основатель 04». Занятые игроками имена/теги и существующие ID защищены. Сохранённые территории не перераспределяются; новая генерация использует четыре основателя, пустые галактики остаются пустыми.
- Web хранит HTML/CSS/JS/локализации на диске отдельными проверенными пакетами. Поддерживаются установка ZIP, синхронизация опубликованного тега, атомарная активация, предыдущие ревизии и откат. HTML закрепляет одну ревизию, неизменяемые файлы кешируются браузером.
- Cosmic обслуживает игровой API и больше не встраивает фронтенд. CDN занимается графикой и приватными изображениями руководства. Web напрямую передаёт API/HTTP/WebSocket в соответствующие службы с сохранением cookie/Origin и блокировкой внутренних маршрутов.
- Web и CDN не подключаются к PostgreSQL. Отдельная NATS identity `web` получает сигналы CDN и инвалидирует кеш публичного каталога графики; TTL и reconnect обеспечивают сверку без зависимости раздачи от брокера. NATS не подтверждает загрузку ассетов конкретным браузером.
- Миграция 300 один раз обновляет общую версию игры в БД; последующие операторские изменения переживают обычные перезапуски.

## Обновление с 0.29.0

**Входной адрес игры теперь принадлежит Web.** По умолчанию Web занимает прежний внешний `:8083`, а CDN переводится на внутренний `127.0.0.1:8084`. Cosmic остаётся на приватном `:8080`, Planet — `:8081`, Chat — `:8082`.

Сохраните `database.schema`, каталоги CDN, файл служебного токена и журнал Chat. Остановите прежние процессы, обновите внутренний URL CDN в Cosmic, добавьте конфигурацию Web и проверьте public_origin/allowed_origins по адресу браузера. Первым запустите Cosmic для миграций, затем остальные службы. Дождитесь готовности пакетов Web/CDN; они автоматически получаются из опубликованного релиза либо устанавливаются локально через `--install-pack`.

[Полная инструкция, конфиги, NATS, каталог файлов и откат](../docs/operations/web.ru.md).

## Поставка и проверки

Пять статических ELF Linux amd64, отдельные ZIP графики и интерфейса, два JSON-индекса, build manifest с исходным commit и SHA256SUMS. Node.js/Python не нужны для работы служб.

Перед выпуском проверены 84 UI-теста; интеграционный набор — 161 PASS и 17 опциональных SKIP, дополнительные реальные браузерные сценарии через Web, native NATS и race-проверки. Подтверждены совместный запуск пяти служб, авторизованный API через Web, 70 секунд ходьбы без переподключения и повторное открытие страницы без новых PNG-передач из CDN. Рабочая БД владельца при проверках не использовалась.
