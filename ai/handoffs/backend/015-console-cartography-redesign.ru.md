# Переработка карт и оболочки терминала · Web 0.30.5

19 ноября 2026 года. Владелец оценил предыдущую правку как слишком небольшую
и поручил кардинально изменить карты, затем отдельно добавил «и сам интерфейс».
Сохраняются функционал и выпуск только Web. Ветка `feature/cartography-redesign`.

**Статус: Web 0.30.5 опубликован.**
[Релиз](https://github.com/yomezza/astrajourney/releases/tag/v0.30.5),
[успешный workflow](https://github.com/yomezza/astrajourney/actions/runs/44456850823).
Коммит поставки и тег: `f6dc109`. Изменения интегрированы в main.

## Что изменено

- `web/features/maps/cartography.js`: отдельный Canvas-рендерер оформления.
  Кешируемый фон, свечение звёзд с различием известных/неизвестных систем,
  корона центрального светила, тени на планетах, рамки станций, подписи,
  шлейфы маркеров кораблей, направленные сегменты маршрута.
  Рендерер не выполняет запросы и не меняет мир. Слой звёзд пересобирается
  при изменении проекции/знаний/размера, а не для каждого фонового кадра.
- `web/features/maps/galaxy.js`: шапка, переключение режимов, карточка выбора
  поверх поля карты, счётчики и строка состояния. Существующие действия
  открытия/маршрута вызываются через прежние функции. Подписи стоящих рядом
  кораблей разнесены без изменения позиций их hit targets. Маркеры объектов
  системы увеличены одновременно с радиусами выбора. В каталоге сохранён
  `stationLabel`, добавлена строка типа объекта. Личные значения новых
  элементов и слой звёзд очищаются при signedout.
- `web/styles/maps.css`: новая композиция шапки/поля/инспектора/карточки,
  адаптация к ширине окна. Прежние контролы и действия остаются доступными.
- `web/styles/console.css`, `web/index.html`: оболочка всего терминала —
  шапка, навигация, активные разделы, окна, вкладки, карточки, таблицы, поля
  и начальная загрузка. Новых внешних шрифтов или графических файлов нет.
- `web/ui/windows.js`: вместо фиксированной верхней границы 62px применяется
  высота шапки из CSS; восстановление, перемещение и разворачивание учитывают
  новую оболочку. Закрепление, связки и сохранённые положения не удалены.
- `web/features/shell/navigation.js`: начальный размер карты 1280×800;
  прежние сохранённые размеры не сбрасываются. Добавлены переводы новых
  заголовков в ru/en.

API, правила, маршрутизация по галактике, поиск, фильтры, заметки, закладки,
контекстные действия и вход на поверхность остаются на существующих путях.
БД и службы Cosmic/Planet/Chat/CDN не менялись. Web имеет версию 0.30.5.

локальный интерфейс с синтетическими DTO, показывает 320 демонстрационных

## Обновление

Только Web-бинарник/пакет. В секции `[web]` задать `release_tag='v0.30.5'`
и `sync_enabled=true`, перезапустить Web, затем обновить страницу после
активации пакета. Остальные службы остаются на 0.30.3; API astra-api-v1
прежний. Игровая версия из БД не подменяется версией Web. Выпуск сохраняет
общий GitHub Latest на полном 0.30.3 для синхронизации графики CDN.

Подтверждены шесть публичных файлов отдельного Web-релиза, HTTP 200.
Скачанные Web JSON и build manifest совпали с локальными; единственная
служба в manifest — Web. Общий GitHub Latest по-прежнему указывает на 0.30.3.
Доказательства публикации сохранены в `dist/release-v0.30.5/`.

Следующий шаг: владельцу активировать Web-пакет 0.30.5 и оценить интерфейс
на своей установке. Публикация не обновляла его службы или БД удалённо.
