# Сверка интерфейса чата с макетом архитектора

Эталон: [передача v13](../ideas/chat-service/15-frontend-prototype-handoff-v13.ru.md) и [HTML v13](../ideas/chat-service/chat-service-ui-prototype-v13.html). Исправления выпущены в 0.24.1.

| Расхождение в 0.24.0 | Причина | Исправление |
|---|---|---|
| Лишняя верхняя полоса и два заголовка | Общая оболочка окна оставалась над собственным заголовком чата | Родной заголовок перенесён внутрь chat-root и используется как единственный. Перемещение, клавиатура и размер обслуживаются прежним менеджером окон; при домашнем закреплении скрытая оболочка не перемещается |
| Пустая полоска перед вводом | Узел предпросмотра ответа всегда был виден, несмотря на отсутствие текста | Явное `hidden` при пустом ответе и во всех путях отмены/отправки/смены вкладки |
| Меню ПКМ иногда обычное, а оформление отличается от макета | Выбор компактной темы зависел от `document.activeElement`; применялись лишь часть размеров, а фон/рамка/шрифты оставались от общего меню | Опциональные owner/theme в существующем `UI.menu`, явная тема для чата, полный локальный стиль v13. Отдельного движка контекстных меню нет |
| Вложенный перенос не показывал текущую папку | Не передавалось состояние checked | Пункты `menuitemradio`, текущая папка с отметкой, «Без папки (Все)» и обычное неизменяемое представление «Все» |
| Избранное выглядело как общая переписка | Использовался общий рендер строк сообщений и постоянный композер | Карточки заметок/копий, доступные папки непосредственно в панели, отдельное создание заметки |
| Меньше места для истории | Поиск всегда раскрыт, пустой ответ занимал строку, повторялся заголовок | Поиск по кнопке, скрытие пустых элементов, один заголовок, компактные размеры элементов |
| Ники в списке пилотов сжимались | Сетка макета ожидала больше DOM-колонок, чем создавал рендер | Согласованы колонки аватара, имени и действий |
| Подсказки выглядели как обычный текст | Подготовленные стили v13 не использовались рендером | Содержимое с двумя строками служб и цветными квадратами, отдельное оформление прочтения в общей системе tooltip |

## Проверка

Один прицельный browser-тест `tests/ui/chat-layout.test.mjs` загружает CSS непосредственно из HTML архитектора в изолированный контекст и сравнивает фон, рамку, минимальную ширину, отступы, шрифт и высоту строк с настоящим `UI.menu`. Проверяет ЛКМ и ПКМ при внешнем фокусе, отметки вложенных папок, исчезновение пустого ответа, один заголовок, drag и сохранение позиции после dock/undock. Остальные темы меню проверяются на отсутствие утечки компактного стиля.

Также пройдены связанные проверки общего менеджера окон/жизненного цикла и существующий `TestChat240FiftyConnections` с Chromium и PostgreSQL; сценарий создания заметки приведён в соответствие с v13. Полный игровой функционал и экономика для этой визуальной поправки повторно не прогонялись.
