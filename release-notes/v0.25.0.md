# Astra Journey 0.25.0 — первооткрыватели, база знаний и Planet Mode

- Личное исследование закрепляет первооткрывателя системы и каждой раскрытой планеты. Первооткрыватель может один раз дать глобальное имя; администратор — отдельно исправить его с причиной. Стабильные ID, маршруты и география сохраняются. Старые исследования и территории основателей защищены от ошибочного присвоения.
- В существующий модуль «Исследования» добавлены каталожные коды, сведения об открывателях и управление названиями. Готовые колонии переименовываются отдельно, с текущими правами владельца/корпорации и суточным интервалом.
- «Руководство пилота» оформлено по утверждённому Original C: два столбца, поиск, категории, избранное, недавние материалы и прокрутка без сброса. Игровые справочники объединены с опубликованными статьями PostgreSQL; добавлен административный редактор RU/EN с preview, историей, сравнением редакций и отдельной публикацией.
- Изображения PNG/JPEG/WebP проверяются и перекодируются в PNG вне webroot. Встроенные SVG выбираются по manifest key; загрузка пользовательского SVG пока недоступна.
- Высадка открывает цельный Planet Mode, сохраняя скрытые окна космоса и общий чат. Используется одна загрузочная заставка; F5 восстанавливает прежний визит.
- Нормальный возврат выполняется через исходный посадочный модуль и одноразовое серверное разрешение. Закрытие вкладки/выход из аккаунта не телепортирует персонажа. Для подтверждённых серверных неисправностей предусмотрено отдельное восстановление с аудитом.

Выпускаются **Cosmic 0.25.0 и Planet 0.25.0**, Windows amd64 и Linux amd64. **Chat остаётся 0.24.14.** Обновите Cosmic и Planet вместе: остановите обе службы, сохраните backup, запустите новый Cosmic для штатных миграций, затем новый Planet. Старые схему БД, конфиг и данные сохраняйте.

Пройдены адресные проверки PostgreSQL/Go, короткие настоящие браузерные сценарии и регрессии интерфейса. Windows-бинарники проверяются как PE amd64; запуск на Windows в облачной Linux-среде не выполнялся.
