# Cosmosimulator Chat 0.24.7 · N1, общий диспетчер A1

Реализован общий Chat EventDispatcher с WSRegistry, bounded/coalesced sync,
metadata outbox reader, SQL RecipientResolver и локальными уведомлениями после
COMMIT. Отдельные session/scope/lease проверки, текущие ACL, UUID-idempotency,
модерация и erasure journal сохранены. HTTP/WS протокол не менялся.

По умолчанию остаётся `legacy`. Для опционального A1:
`chat.dispatcher_mode='a1'` в отдельном TOML Chat или `CHAT_DISPATCHER_MODE=a1`
в ENV-режиме. Нормальный fallback 10s, degraded 2s, overlap 60s; откат — legacy
и перезапуск Chat. Секция `[nats]`, режимы A2/B1 и JetStream не включены.

Обновляется **только Chat EXE**. Cosmic остаётся 0.24.6, Planet — 0.24.4,
схема БД прежняя, повторная выдача SQL-прав не нужна. Если у трёх служб был
общий TOML, выделите отдельную копию Chat: старые Cosmic/Planet EXE не знают
новых dispatcher полей. Не меняйте существующий erasure journal.

Проведены Go unit/integration/race, restricted-role/spatial/private/session/
slow-writer/SQL recovery проверки и реальный backup/restore drill. Выполнено
нативное сравнение legacy/A1 с 50/100/200/256 WS на отдельной PostgreSQL.
Полный отчёт и измерения: docs/operations/nats-n1/README.ru.md.
N2 не начинался; рабочий NATS/службы/база владельца не изменялись.
