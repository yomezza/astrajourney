# Astra Journey 0.30.3

Исправление запуска интерфейса после 0.30.2. Только Linux amd64.

В редакторе галактик две разные переменные получили одинаковое имя `snapshot`
в одной области видимости. Браузер выдавал `SyntaxError: Identifier 'snapshot'
has already been declared` и останавливал загрузку общего модуля приложения
ещё до запросов авторизации. На экране оставалось «Подключение к серверу»;
открыть космический или планетарный интерфейс было невозможно, даже когда
все службы работали и JavaScript-файлы возвращались с HTTP 200.

Переменная локального каталога переименована в `catalogSnapshot`; отдельная
переменная предпросмотра сохранена. Кеширование переключений галактик,
проверка эпохи сессии и применение предпросмотра остаются на своих путях.
Остальные оптимизации 0.30.2 сохранены.

## Обновление

Замените пять Linux-бинарников и установите **новый Web-пакет**.
В существующем конфиге измените закреплённую версию:

```toml
[web]
sync_enabled = true
release_tag = 'v0.30.3'
```

Сохраните свои остальные параметры, каталоги данных и токены. Первым
запускается Cosmic, затем Planet, Chat, CDN и Web. Web скачает и активирует
пакет из этого релиза. После активации обновите страницу игры.
При отключённой синхронизации установите ZIP с именем из
`astra-journey-web.json` через `--install-pack`.

Для устранения именно синтаксической ошибки исправленный Web-пакет совместим
с API служб 0.30.2 (`astra-api-v1`). Полный комплект 0.30.3 также включает
одноразовую миграцию 303, обновляющую общую версию игры в `game_release`;
новых игровых таблиц и индексов нет. Рабочая БД при подготовке не изменялась.

Графический пак CDN прежний — повторная установка не требуется.
Исторические бинарники, пакеты и релизы сохранены.

## Поставка и ограничения

Пять статических Linux amd64 ELF, build manifest, Web/graphics ZIP,
JSON-индексы, TOML-примеры и SHA256SUMS. Windows-сборок нет.
Локальные функциональные, браузерные и нагрузочные тесты по ранее заданному
ограничению владельца не запускались. Подготовка файлов выполняется штатным
сборщиком, публикация — штатным release workflow с проверкой целостности.
Ошибка установлена по коду и подтверждена сообщением браузера владельца.
