# Astra Journey 0.31.3 — MATRIX × STUDIO

Космический терминал открывается как рабочая диспетчерская. Компактная телеметрия показывает баланс, положение и игровое время. Вкладки открывают разные раскладки карточек. Для пустого стартового профиля доступны «Командование», «Добыча» и «Торговля».

- Карточки показывают флот, карту текущей галактики, операции добычи и исследований, рыночные предложения, данные корабля и трюм. Полные игровые модули открываются из карточек и боковой навигации.
- Карточки можно перетаскивать, переставлять кнопками, расширять и открывать как отдельные окна. Порядок, ширина, позиция окна, выбранный корабль и фильтр трюма сохраняются на аккаунте.
- Чат и уведомления используют прежние интерфейсы и контракты. При закреплении чата на главной широкий экран выделяет ему правую колонку.
- Переключение раскладки меняет контекст просмотра. Игровые действия выполняются через действующие игровые модули.

## Обновление Linux amd64 с 0.31.2

1. Скачайте бинарник Cosmic и Web ZIP из этого релиза. Скачайте `SHA256SUMS` и проверьте файлы командой `sha256sum -c SHA256SUMS` из каталога комплекта.
2. Сохраните резервную копию PostgreSQL, прежний Cosmic и активную ревизию Web. Остановите Web, Chat и Planet, если они используются, затем Cosmic. Замените Cosmic и запустите его с прежним конфигом. Дождитесь успешного запуска и отметки версии 0.31.3. Запустите Planet и Chat.
3. В общем TOML для ручной установки задайте `[web]` → `sync_enabled = false`. Пока Web остановлен, запустите прежний Web 0.31.1 с тем же `CONFIG_FILE` и флагом `--install-pack /path/to/astra-journey-web-REVISION.zip`. Затем запустите Web штатно.
4. Проверьте `/web/api/v1/health/ready`, вход, сохранение карточки после перезагрузки, карту, чат и уведомления.

Для отката интерфейса на остановленном Web используйте `--activate <предыдущая-ревизия>` и запустите службу. Бинарники Web, Chat, Planet и CDN и графический пакет CDN для этого обновления не требуются.
