# Голографические новости на главной (демоверсия)

Это **экспериментальный** виджет для `scripts/frontend-generation`.
Он показывает только вымышленные новости, не использует Go, БД, настоящий
сервис новостей и не изменяет оригинальный frontend Cosmosimulator.

## Где находится

На главной под блоком показателей пилота: справа от закреплённого чата.
Если чат откреплён, проектор занимает центр нижней области, а не оставляет
пустую колонку. На экранах до 1060 px блоки становятся вертикальными.
Новости не скрываются при ширине 880 px и меньше.

Над проектором расположен штатный `select` с заголовком
**«Отображение новостей»**. В нём три экспериментальных решения художника:

- **A — Голографическая типографика**: световая типографика, тонкая
  сканирующая разметка без обычной непрозрачной карточки.
- **B — Информационный терминал**: полупрозрачная плоскость, световая
  шкала, более строгая текстовая иерархия.
- **C — Объёмная сводка**: небольшие тематические векторные голограммы
  внутри текстового слоя.

Выбор применяют сразу, без полной перерисовки DOM. Класс оформления
переключается у **одного** виджета, а две записи остаются теми же.
Выбранный вариант сохраняется через исходный `Preferences` под
`cosmosim-demo-news-variant-v1` и восстанавливается после обновления
страницы. Стартовое значение — **B**, только для удобства сравнения,
не окончательное решение.

## Художественные ресурсы

В `assets/` находятся **неизменённые Git blobs** из
`docs/ideas/news/` (не CSS-рисунки и не растровые заменители):

| Ресурс | Роль |
|---|---|
| `news-projector-base.svg` | Физический проектор снизу |
| `news-projection-beams.svg` | Световые проекционные потоки |
| `news-panel-left.svg` | Левая парящая панель |
| `news-panel-right.svg` | Правая парящая панель |
| `news-all-button.svg` | Центральный голографический контроллер |

Они скопированы на уровне **самих Git-объектов**, сохраняя исходные
байты, анимацию, геометрию и SVG viewBox. Смена A/B/C никак не влияет
на эти пять общих слоёв. HTML-текст помещён в отдельные
`.news-float-track` и следует фазе парения с периодами 6.8/7.5 с,
указанными художником. Стили перенесены из
`docs/ideas/news/text-variants/shared/style.css` в
`news.css` с пространством имён `.news-hologram-widget`.
Оригинальный demo.js не подключается: его лабораторные контролы
несовместимы с главной страницей.

**Обновление SVG после правок художника:** в рабочем Git-репозитории
сверьте новые файлы из `docs/ideas/news/`, затем обновите одноимённые
копии в `scripts/frontend-generation/mock/news/assets/` и запишите
коммит только в этот каталог. Для копирования из локального checkout
подойдёт `cp` / `Copy-Item`, без регенерации SVG. После публикации
`update.py` скачает новые копии при следующем запуске. Обновлять
`docs/ideas/news/` в роли frontend-разработчика не требуется.
Проверка sha в `tests/test_news_home.py` фиксирует текущую редакцию
художественных слоёв — при одобренной редакции её SHA обновляют отдельно.

При запуске страницы браузер запрашивает только локальные пути
`/mock/news/assets/*.svg`, не обращается напрямую к GitHub. Все
пять SVG включены в обновление демопрограммы и работают после
`python launch.py --offline`, если локальные файлы уже установлены.

## Источник тестовых новостей

`news.json` — **один** набор из 12 записей, с неизменными ID,
категориями, временем в UTC, RU/EN заголовками и описаниями.
`star_id` / `object_id` согласованы с вымышленным каталогом
`mock/registry.py`: Эдем, Альтаир, Вега-9, маяки и планеты.
По умолчанию на главной показываются **две последние новости**;
переключение варианта не выбирает новые.

Все новости доступны по центральной HTML-кнопке **«Все новости»**.
Она открывает **настоящее окно `Modules`**, с заголовком, списком
новостей, временем и текстом. Дополнительная главная или iframe
не создаются. Открытие окна и смена A/B/C не влияют на чат и
лабораторию UI/UX.

Язык определяется из оригинального `I18n` и обновляется событием
`languagechange`. Даты показываются как UTC, чтобы записанные
отметки не зависели от часового пояса тестового окружения.

### Сценарии проверки

Для специальных состояний добавьте URL-параметр
`?news_case=...`:

| Сценарий | Проверка |
|---|---|
| `normal` | Две свежие новости и полный список из 12 |
| `long` | Очень длинный заголовок |
| `nodesc` | Одна запись без описания |
| `one` | Доступна только одна новость |
| `empty` | Нет новостей, обе проекции в empty-state |
| `error` | Ошибка фиктивного локального источника, сообщение и кнопка повтора |

Эти сценарии предназначены только для тестирования. На главной
обычной демоверсии нет второго лабораторного селектора.

## Как проверить

Запуск обычный:

`python update.py`
`python launch.py`

Проверки Python:

`python -m unittest discover -s tests -v`

Дополнительный **реальный браузерный** скрипт (потребуются Playwright и
локальный Chromium):

`python -m playwright install chromium`
`python tests/browser_news_smoke.py`

Он проверяет переключение A → B → C → A, восстановление выбора,
модуль «Все новости», локальную загрузку SVG, RU/EN,
закрепление/открепление чата и размеры 1920, 1440, 1280, 1024,
881, 880, 760 и 390 px; сохраняет screenshots.
Наличие скрипта не означает, что браузерный прогон уже выполнялся.

## Ограничения

- Все события вымышленные, дата и время фиксированы в fixture.
- Никакого настоящего news API, редактора, серверного обновления или
  автоматической публикации новостей нет.
- Изображения и HTML-парение используют одинаковые периоды, но изолированные
  SVG-анимации не имеют общего программного таймлайна с HTML.
- Заголовки в узких проекциях ограничены тремя строками; полный текст
  доступен в title/aria-label и в окне «Все новости».
- Художественные SVG редактирует отдельный SVG-разработчик;
  выбор A/B/C пока экспериментальный.

Чат v13, «Исследования» v13, модуль UI/UX и исходники
`internal/server/web/` не перерабатывались.
