# Cosmosimulator Chat 0.24.8 · N2, PostgreSQL LISTEN/NOTIFY A2

Добавлен третий режим общего диспетчера: `a2`. Один выделенный PostgreSQL-сеанс
подписывается на `cosmos_chat_<md5(DB_SCHEMA)>` до начального сканирования,
принимает пустые NOTIFY и переподключается с повторной подпиской и сверкой.
Локальные post-COMMIT wakeups в A2 отключены; общий SQL fallback сохранён.

A1/A2 получили независимую авторизованную сверку состояния каждые 30s:
поздний меньший outbox ID вне overlap больше не оставляет UI навсегда устаревшим.
Это восстановление текущего состояния, не строгий replay каждого hint.

По умолчанию сохранён `legacy`, доступен откат на A1/legacy. Проверены
функциональные, интеграционные и race-сценарии; нагрузочные бенчмарки N2
намеренно не выполнялись. [Полный отчёт](https://github.com/yomezza/cosmosimulator/blob/main/docs/operations/nats-n2/README.ru.md).

**Только изолированный этап N2.** Установка SQL-триггера на рабочей базе
не разрешалась и не выполнялась. Chat EXE не запускает DDL; цепочка Cosmic,
SQL-права, игровые API и erasure journal сохранены. Релиз содержит только
Chat EXE; Cosmic остаётся 0.24.6, Planet — 0.24.4. Отдельный Chat TOML и прежний
журнал удалений сохранять. NATS/B1/JetStream и N3 не реализовывались.
