# Astra Journey 0.31.4 — интерфейс MATRIX × STUDIO

Космический терминал получил компактную навигацию по группам и общий каталог игровых модулей. Каталог открывается из шапки, мобильной панели или по Ctrl+K / ⌘K. Из него можно перейти к модулю или вернуться в уже открытое окно.

- Вход, корабль и трюм, рынок, добыча, логистика, исследования, планировщик, карты, колонии, руководство и администрирование используют общую систему элементов MATRIX. Панель управления планетой соответствует терминалу по цветам и оформлению.
- Панели окон, карточки, каталог и навигация используют согласованные значки. Кнопки карточек указывают, куда ведут. Добыча и планировщик разворачивают формы и действия в одну колонку на маленьком экране.
- На телефоне игровые окна занимают доступную ширину, а навигация по рабочим пространствам, картам, модулям и чату остаётся под рукой. Размеры и позиции окон, сохранённые для компьютера, сохраняются при входе с телефона.
- В списке флота можно выбрать корабль для текущего рабочего пространства. Такой выбор меняет контекст карточек и сохраняется в раскладке аккаунта. Активный корабль и игровые операции по-прежнему управляются из соответствующих игровых модулей.
- Чат и уведомления продолжают использовать своё рабочее оформление и доступны во всех рабочих пространствах.

## Обновление с 0.31.3

1. Скачайте из релиза Web ZIP, инструкцию `UPDATE.ru.md` и файлы, перечисленные в `SHA256SUMS`. В каталоге скачанных файлов выполните `sha256sum -c SHA256SUMS`.
2. Запишите текущую ревизию Web из `/web/api/v1/health/ready`. Для ручной установки задайте `sync_enabled = false` в секции `[web]` действующего TOML и остановите Web.
3. Запустите существующий Web 0.31.1 с тем же `CONFIG_FILE` и аргументом `--install-pack /path/to/astra-journey-web-REVISION.zip`. Запустите Web штатно.
4. Проверьте новую ревизию в `/web/api/v1/health/ready`. В браузере проверьте вход, рабочие пространства, карту, чат и уведомления.

Комплект обновляет внешний Web-пакет. Он рассчитан на Cosmic 0.31.3 и уже установленный пакет графики CDN. Номер версии игры в шапке берётся из Cosmic. Для возврата к прежнему интерфейсу остановите Web, запустите его с тем же конфигом и `--activate <предыдущая-ревизия>`, затем запустите службу штатно.
