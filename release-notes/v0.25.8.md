# Astra Journey 0.25.8 — pixel art, настройки Planet и WASD

- Планетарный сектор полностью переведён на предоставленный новый текстурпак:
  грунты, вода с четырёхкадровой анимацией, растительность, камни, посадочный
  модуль, эффекты и два восьминаправленных атласа персонажа с ходьбой/idle.
  Старые 25 PNG и графические обходы удалены из актуального исходного кода;
  старые релизы сохранены. PNG нового пака не перерисовывались.
- Добавлена кнопка «Настройки»: мышь по умолчанию или клавиатура WASD.
  Выбор сохраняется для аккаунта. Поддерживаются физические клавиши при русской
  раскладке. В режиме клавиатуры клик задаёт маршрут, WASD его отменяет.
- Серверное движение по направлению имеет ту же скорость по диагонали и те же
  препятствия; клиент не задаёт координаты. Нет запросов на каждый кадр.
  Отпускание, потеря фокуса, скрытие страницы, ввод в чат/формы, отключение и
  выход из режима сбрасывают клавиши. Обработчики при повторном входе не дублируются.
- Новые URL/версия ресурсов и браузерный кэш; графика сектора остаётся lazy.
- Включено ранее диагностированное исправление рывков: обычное продвижение
  игрока в Cosmos больше не перечитывает полный JSON мира под общей блокировкой.
  Сохранены связанные журналы Cosmos/Planet/Chat и браузера.

Нет отдельных спрайтов пучков зелёной и сухой травы: эти слоты явно заменены на
маленькие сиреневые кусты и опавшие листья из нового пака. Декоративные слоты
сохраняют свою проходимость. Дополнительные материалы построек/фермы импортированы,
но новые игровые здания и ресурсы этой заменой не создаются.

География, коллизии и логика колонизации сохранены. Cosmos отвечает за общую
поверхность и колонизацию, Planet — за симуляцию внутри сектора. Новых миграций БД нет.

Сборки: **Cosmic, Planet и Chat для Linux amd64 и Windows amd64**.
Обновляйте Cosmic и Planet вместе. Остановите сначала Chat/Planet, затем Cosmic;
после замены запустите сначала Cosmic, потом Planet и при необходимости Chat.
Сохраните прежний TOML, `database.schema`, пользовательские данные и erasure journal.
После обновления перезагрузите браузерную вкладку. Мышь продолжает работать без
включения WASD в настройках. Подробный отчёт: docs/design/planet-pixelart-v1/README.ru.md.

Проверены настоящий браузер с Go/PostgreSQL, движение мышью и WASD, скорость по
диагонали, столкновения, Chat input, blur/hidden, повторный вход, два аккаунта,
resume/переходы/возврат, кэш и оригинальность ресурсов; movement tests под race.
Windows EXE проверены как PE x86-64, но непосредственно на Windows здесь не запускались.
