# Подготовка выпуска 0.30.1 · Linux amd64

**Статус на 18 ноября 2026:** исходники закоммичены, пять служб и пакеты
собраны, файлы отправлены в `origin/fix/chat-and-background-refresh`.
Публичного релиза и нового тега нет; main не менялся.

Основание — команда владельца «сделай коммит, и подготовь релиз». Предыдущее
поручение не запускать проверки сохранено: новые функциональные, браузерные,
race- и нагрузочные тесты в этот этап не запускались. Сборка выполнена обычным
релизным упаковщиком с его встроенными проверками формата/ресурсов, без запуска
игровых служб и без обращения к рабочей БД.

исходный commit одинаков, `source_dirty=false`; исторические бинарники
и контрольные суммы сохранены. Новых Windows-сборок нет.

`dist/release-v0.30.1/astra-journey-v0.30.1-linux-amd64.tar.gz` — 30 215 382 байта.
Внутри пять служб, оба ZIP/JSON, manifest, шесть TOML-примеров, release notes
и отдельный SHA256SUMS только для содержимого комплекта. Рядом сохранён
`*.tar.gz.sha256`. Архив не добавлен в Git повторно; отдельные релизные файлы
уже находятся в отправленном коммите поставки.

В версии служб теперь 0.30.1. Новая миграция **только метаданных** `schema301.sql`
один раз обновляет общую версию клиента в `game_release`, сохраняя последующие
операторские изменения при обычных перезапусках. Она включена в инициализацию
Cosmic, но ни к какой действующей БД в этом этапе не применялась. Примеры
конфигурации Web закреплены на `v0.30.1`; существующую установку с явно заданным
`web.release_tag` нужно переключить на новый тег и установить новый Web-пакет.

Git fetch/push доступны. REST API GitHub (`api.github.com`) заблокирован
сетевым allowlist этой среды, поэтому отдельный GitHub Release draft через API
не создавался. Подготовка завершена файлами, release notes и удалённой веткой.
Не пушить `v0.30.1` только ради подготовки: workflow `release.yml` публикует
релиз автоматически при push тега. Публикация — следующий отдельный шаг по
команде владельца. Утверждать успешный новый 100-player прогон нельзя:
он был остановлен в предыдущем этапе по его просьбе.
