## Версии, обновление и действия

Все пять служб имеют версию 0.30.2. Добавлена только миграция метаданных
`schema302.sql`: один раз обновляет `game_release`; последующие ручные
изменения переживают обычный перезапуск. Историческая schema301 сохранена.
Рабочая БД и служебные конфиги владельца при подготовке не изменялись.

В примерах `[web].release_tag='v0.30.2'`. Существующей установке нужно заменить
пять Linux-бинарников, закрепить новый Web tag или вручную установить Web ZIP,
запустить первым Cosmic, затем Planet, Chat, CDN и Web и обновить страницу.
Порты, режим чата и настройки NATS автоматически не меняются.

Выполнена команда:

```sh
python3 scripts/build-release.py v0.30.2 --platform linux --source-ref 36d1b96
```

Сборка завершилась успешно для всех пяти служб. Встроенные действия упаковщика
подготовили внешние пакеты, проверили доверенные SVG, формат статических ELF
и рассчитали SHA256. Локальные go test, go vet, Node/Playwright, EXPLAIN,
нагрузочные прогоны и запуск игровых служб не выполнялись. Проценты ускорения
и новая вместимость сервера не измерены. Автоматические workflow GitHub
сохраняют штатные триггеры; их результаты учитываются отдельно.

REST API GitHub из этой среды отвечает Forbidden. Git fetch/push и публичные
страницы GitHub доступны, поэтому публикация идёт через существующий tag
workflow, а подтверждение — по публичной странице и файлам релиза.

## Подтверждение публикации

Публичная страница возвращает HTTP 200 с заголовком Release Astra Journey
v0.30.2. Список assets содержит все **17 файлов поставки**: пять Linux-служб,
build manifest, два ZIP, два JSON-индекса, шесть TOML-примеров и SHA256SUMS.
Публично скачанные build manifest и оба JSON-индекса побайтно совпали с
локальными. Manifest указывает только linux/amd64 и общий источник
`36d1b960078e3f20ae082cf4867045f794c0d53e`.

Доказательства выдачи страниц/JSON и состояние workflow сохранены локально
в `dist/release-v0.30.2/`. Это подтверждение поставки, а не функциональный
или нагрузочный тест игры. Другие автоматически запускаемые workflow этим
отчётом не объявляются успешными.
