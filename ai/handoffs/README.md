# Передача задач между чатами (handoff)

Этот каталог хранит **проверенные отчёты** о конкретной работе. Пока здесь только правила — готовые отчёты не перенесены автоматически.

Используй [шаблон](../templates/handoff.md); для каждой новой передачи можно создать файл `<role>/<NNN>-<slug>.md`, с тем же ID, что и у исходного `ai/prompts/<role>/<NNN>-<slug>/prompt.md`.

Обязательно разделяй:
- что **реально сделано** и опубликовано (GitHub SHA, ссылки);
- что **проверено** (команды, запуск стенда, тесты);
- что **не выполнено**, заблокировано или осталось на уровне идеи;
- что должен сделать следующий чат.

Не вставляй секреты, содержимое приватных БД, реальные токены или конфигурации сервера. Сохраняй ссылки на **канонические** документы, не копируй их целиком.
