# Astra Journey 0.31.10 — категории идей

Администраторы могут добавлять, переименовывать, отключать и возвращать категории в разделе «Предложения игроков» → «Категории предложений». PostgreSQL хранит категории и связи с уже отправленными идеями. Отключённая категория остаётся у существующих предложений.

В каталоге сообщества сначала видны одобренные идеи, затем предложения на рассмотрении. Отклонённые предложения доступны автору и администраторам.

## Обновление с v0.31.9

1. Скачайте файлы и проверьте их командой `sha256sum -c SHA256SUMS`.
2. Сохраните резервную копию PostgreSQL и текущих файлов. Обновите Cosmic для Linux amd64 и запустите его с действующим конфигом. Миграция сохранит категории существующих идей.
3. Остановите Web и установите новый веб-пакет через `--install-pack` с прежним `CONFIG_FILE`. При ручной установке используйте `sync_enabled = false`. Затем запустите Web.
4. Проверьте версию `0.31.10` в `/api/server-status` и ревизию Web из `astra-journey-web.json` в `/web/api/v1/health/ready`.
