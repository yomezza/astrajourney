# Cosmosimulator Chat 0.24.9 · N3, Core NATS B1

Добавлен опциональный режим `b1` к прежнему общему диспетчеру Chat. После
PostgreSQL COMMIT передаётся bounded/coalesced Core NATS hint на единственный
subject `cosmos.v1.signal.chat.outbox.changed`. Строгий envelope ≤2 KiB не
содержит текста переписки, токенов и ID Private. Subscriber повторно читает
PostgreSQL и применяет прежний RecipientResolver/ACL; локальный wake не
подменяет получение сигнала NATS.

Реализованы `[nats]`/ENV только для Chat, TLS с проверкой CA/SAN, static login
`chat`, защищённый password_file, автоматическое переподключение/переподписка,
сверка после восстановления, ограниченные очереди и отменяемый shutdown.
Отказ сети/брокера/публикации не отменяет SQL COMMIT и не блокирует игровой Chat.
Fallback и независимая сверка сохранены, `legacy` остаётся default, A1/A2
доступны для отката. Космический и планетарный API не менялись.

На изолированном TLS-брокере и полной PostgreSQL проверены commit/rollback,
UUID, ACL, реальные WS, отказ/перезапуск, пропущенный Core сигнал, поздний COMMIT,
Private/Corporation/Planet, сессии/lease и rollback. Нагрузочных сравнений нет.
[Полный отчёт и подготовка Windows](https://github.com/yomezza/cosmosimulator/blob/main/docs/operations/nats-n3/README.ru.md).

В релизе только Chat EXE; Cosmic остаётся 0.24.6, Planet — 0.24.4. Сборка также
сохранена в downloads, прежние версии не удалены. Рабочие PostgreSQL, cosmoNATS,
Windows Services и конфиги не изменялись. Production подключение не выполнялось.
N4/N5, другие subjects, Request/Reply, JetStream, JWT/NKey не реализованы.
