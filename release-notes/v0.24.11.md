# Cosmosimulator 0.24.11 — Core NATS N6

Обновлены Cosmic, Planet и Chat. NATS необязателен и отключён по умолчанию;
рабочие Windows службы, PostgreSQL и cosmoNATS не менялись.

- Cosmic: отдельный TLS/static `cosmos` профиль и password_file; после COMMIT
  отправляет сигналы о членстве, ролях, правах, модераторах и запросах удаления корпорации.
- Chat: немедленная SQL-сверка корпоративных/пространственных прав по hints.
  После COMMIT durable cleanup receipt отправляет обратный сигнал Cosmic;
  завершение удаления и возврат средств всё равно зависят от PostgreSQL receipt.
- Planet: postcommit сигналы начала, возобновления, отключения и завершения
  посещения; прежний `planet.sector.changed` сохранён.
- Strict contracts, ограниченные очереди, TLS CA/SAN, разделённые identities и
  exact subjects. Старые и повторные сигналы не применяются как состояние/права.
- При отказе NATS остаются SQL fallback, session/lease/fence проверки и HTTP/WS gateway.

Сохранены поступившие в main изменения окна исследований из другого чата;
Cosmic собран с актуальными встроенными веб-файлами.

В downloads сохранены новые Windows amd64 EXE всех трёх служб и SHA256,
предыдущие версии не удалены. Для NATS нужны **три отдельных** TOML/ENV профиля.
Обновление EXE не включает брокер автоматически. При возврате старого Cosmic
0.24.6 нужно убрать новую секцию `[nats]`, которую старый strict parser не знает.

[Полный русский отчёт, функциональные проверки, будущие ACL и rollback](https://github.com/yomezza/cosmosimulator/blob/main/docs/operations/nats-n6/README.ru.md).
Нагрузочные тесты, profiling, JetStream, Request/Reply, registry, heartbeat и N7 не выполнялись.

### Linux amd64 / Debian 13

Добавлены статические Linux amd64 сборки всех трёх служб из точного тега
v0.24.11. Windows EXE сохранены без пересборки. SHA256 и build.json содержат
новые файлы. [Инструкция запуска и сборки](https://github.com/yomezza/cosmosimulator/blob/main/docs/operations/linux-amd64.ru.md).
