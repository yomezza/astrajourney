# Astra Journey 0.31.6 — идеи сообщества

- В модуле «Предложить идею» появились каталог сообщества, история «Мои идеи» и форма отправки. Поиск по заголовку и описанию, фильтр по категории и сортировка работают по всему каталогу.
- В каталоге видны только одобренные предложения. После отправки игрок может сразу открыть собственную идею и проверить её статус.
- На широких экранах список и описание открываются рядом. На узких экранах можно вернуться из описания к тому же месту в списке.
- Русский стал единственным поддерживаемым языком интерфейса. Прежняя настройка английского при открытии игры заменяется на русский. Система I18n и словари сохранены.

## Установка поверх 0.31.5 на Linux amd64

1. Скачайте файлы релиза в один каталог и проверьте их командой `sha256sum -c SHA256SUMS`. Сохраните предыдущий бинарник Cosmic и запишите текущую ревизию Web из `/web/api/v1/health/ready`.
2. Остановите Cosmic, установите `astra-journey-v0.31.6-linux-amd64` вместо его исполняемого файла и запустите службу с действующим конфигом. При запуске Cosmic добавит в PostgreSQL поле даты публикации. Для идей, одобренных до этого обновления, каталог показывает дату создания.
3. Для ручной установки оставьте `sync_enabled = false` в секции `[web]`. Остановите Web и запустите его существующий бинарник с тем же `CONFIG_FILE` и аргументом `--install-pack /путь/к/astra-journey-web-REVISION.zip`. Затем запустите Web штатно.
4. Проверьте `version` в `/api/server-status` и `revision` в `/web/api/v1/health/ready`. Версия игры должна быть `0.31.6`, а ревизия совпадать с полем `revision` в `astra-journey-web.json`.

Комплект содержит Cosmic и Web-пакет. Для установки пакета подходит действующая служба Web 0.31.1.

Для отката остановите Web и активируйте прежнюю ревизию через `--activate <предыдущая-ревизия>`, затем восстановите прежний бинарник Cosmic и запустите обе службы штатно.
