# Astra Journey Web 0.30.5

Переработка обеих карт и интерфейса терминала. Отдельный выпуск Web,
только Linux amd64. Остальные службы остаются на 0.30.3.

## Карты

- Новая композиция: шапка галактики/системы с переключением режимов,
  полоса поиска, поле навигации, инспектор и нижняя карточка выбора.
- Звёзды отрисовываются светящимися маркерами. Спектральные цвета доступны
  для исследованных систем; неизвестные имеют нейтральное обозначение.
- Глубокий фон с мягкими туманностями, тонкой разметкой и кольцами обзора.
  Декоративные элементы не являются игровыми системами или маршрутами.
- У центральной звезды появились корона и объём; планеты крупнее, с
  освещённой стороной и тенью. Станции получили отдельную рамку-маркер.
- Подписи объектов представлены отдельными плашками, подписи соседних
  кораблей разнесены. У маршрута появились стрелки направления и свечение.
- В инспекторе — каталог объектов с названием и типом. Карточка на карте
  показывает выбранную систему/объект и даёт доступ к открытию/маршруту.
- Свечение звёзд и фон кешируются; нет новых сетевых запросов за текстурами
  и дополнительных анимационных таймеров. Кеш открытия очищается при выходе.

Поиск, фильтрация по галактике, перетаскивание, масштабирование, маршруты,
промежуточные точки, заметки, закладки, флот, контекстные действия и переход
на поверхность сохранены. Размеры маркеров системы согласованы с hit testing;
авторитетное состояние, координаты мира и игровые правила не менялись.

## Интерфейс терминала

Обновлены верхняя панель, боковая навигация, обозначение активных модулей,
заголовки и действия окон, вкладки, карточки, таблицы, поля ввода и стартовый
экран. Карта по умолчанию открывается в большем окне; старые сохранённые
расположения не сбрасываются. Границы перемещения и разворачивания окон
учитывают фактическую высоту новой шапки. Поведение окон и права доступа
к модулям сохранены. Есть адаптация к узким окнам/экранам.

## Обновление

Замените только `astra-journey-web-v0.30.5-linux-amd64` и в существующей
секции `[web]` укажите:

```toml
sync_enabled = true
release_tag = 'v0.30.5'
```

Перезапустите Web, дождитесь активации пакета и обновите страницу.
При ручной установке используйте Web ZIP из `astra-journey-web.json`.
Пакет совместим с прежним `astra-api-v1` и может быть установлен на Web
0.30.3/0.30.4. Cosmic, Planet, Chat, CDN и БД не обновляются. Общая версия
игры в БД остаётся прежней; Web сообщает свою версию 0.30.5.

Новых CDN-ассетов и миграций нет. Публикуются только Web ELF, manifest,
Web ZIP/JSON, конфиг Web и SHA256SUMS. Общий GitHub Latest остаётся на полном
0.30.3, чтобы не нарушать автоматическую синхронизацию графики.

## Проверка

На локальных синтетических данных просмотрены обе карты и переключение
между ними, сохранены снимки экрана; ошибок JavaScript в этом просмотре нет.
Это не запуск на рабочей БД и не полный регрессионный/нагрузочный прогон.
Другие игровые сценарии по прежнему ограничению владельца не прогонялись.
Web компилируется штатным сборщиком, файлы поставки проверяет release workflow.
