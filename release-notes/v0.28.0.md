# Astra Journey 0.28.0

Обновлён интерфейс «Колоний»: список слева, компактная карточка, сводка статусов,
поиск и фильтры, прогресс строительства и доступные действия. «Профиль игрока»
получил новую карточку пилота и показатели. Списки систем и станций оформлены
в общем стиле терминала.

- Системы в списках карт и «Маршрута» относятся только к выбранной галактике.
  Станции рынка и верфи — к галактике активного корабля.
- Версия в шапке и подвале приходит из PostgreSQL через `/api/server-status`;
  старого зашитого номера 0.25.7 больше нет.
- Первооткрыватель системы имеет независимые одноразовые права на название
  системы и каждой планеты. Историческое авторство сканирования сохранено.
  Ледяные и астероидные поля, генерируемые станции игрок не переименовывает.
- «Подробнее» в исследованиях открывает отдельное окно объектов; действие
  переименования планеты находится в компактном меню. Сервер проверяет права,
  фактическую защиту основателей, UUID, повтор и конкурентные операции.
- Добавлены редактируемые словари PostgreSQL с однократным английским наполнением.
  Новая генерация использует их; прежние имена систем и планет сохранены.
- Генерируемые станции получили самостоятельные уникальные английские имена,
  включая старые неактивные станции. Имена построенных станций сохранены;
  исторические коллизии разрешаются детерминированно с аудитом.
- Генератор администратора умеет создавать пустую галактику без основателей
  и станций. Режим сохраняется при расширении.

## Обновление

Остановить службы, сохранить согласованный backup и прежние настройки схемы/данных.
Первым запустить **Cosmic 0.28.0** для атомарной миграции, затем Planet и Chat той же
версии. Добавляется схема словарей (для корня `game` — `game_dictionaries`), раскладка
схем становится 2. Planet schema 10, Chat schema 1 и формат мира 1 не меняются.
Откат к предыдущему Cosmic — только вместе с согласованным backup.

География, коллизии, добыча и движение не изменены. Существующие ID, UUID, корабли,
склады, деньги, договоры и потраченные права сохраняются. Рабочая БД владельца
при разработке не использовалась.

Сборки: Cosmic, Planet и Chat для **Linux amd64 и Windows amd64**, Go 1.26.0,
без CGO. Предыдущие релизы и их файлы сохранены.
