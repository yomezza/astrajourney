# Проверка выпуска 0.29.0

Исполняемая реализация собрана из точного чистого коммита
`71168cf827c1e87f36f050cca81b539534a3d924`, Go 1.26.0. Последующие изменения
выпуска добавляют тест импорта, отчёт и артефакты, без изменения исполняемого кода.
[Машиночитаемый результат](validation.json),
[инструкция установки](../cdn.ru.md).

- Восемь binary: Cosmic/Planet/Chat/CDN, Linux amd64 и Windows amd64; ELF/PE
  проверены, CGO выключен. Контрольные суммы всего downloads проверены.
- `go test ./...` без TEST_DATABASE_URL — PASS; native CDN NATS test включён
  через TEST_NATS_SERVER_BINARY. `go vet ./...` — PASS.
- `go test -race` для CDN, assetpack, configuration и knowledge — PASS.
  Для CDN использован настоящий NATS 2.12.3 с TLS, отдельными ACL, остановкой
  и перезапуском брокера. Публичная графика остаётся доступной при отказе брокера.
- `npm test` — все 79 браузерных/клиентских тестов PASS. Старый тест адреса
  иллюстрации обновлён на новый content hash URL; проверяемое поведение сохранено.
- Полный набор integration root tests распределён на четыре изолированные БД
  с суффиксом `_test`: 176 сценариев, 147 PASS, 29 явных SKIP, 0 FAIL.
  Опциональные browser/benchmark/legacy сценарии не объявляются выполненными.
- На окончательном коде отдельно выполнены проверка отсутствия встроенных
  изображений, Chromium CDN cache/Canvas, публикации/изображений руководства и
  карточек служб. Все пять сценариев PASS.
- Нативно запущены именно релизные Linux-файлы всех четырёх служб из общего TOML
  на отдельной тестовой БД: версии 0.29.0, все ready, все подключены к NATS.
  Проверены вход через CDN, API, четыре административные карточки, раздача SVG
  и защищённые метрики. После проверки процессы остановлены.
- Копирующий импорт прежних UUID.png проверен на сохранение UUID/байтов/исходника,
  повторный запуск и отказ от перезаписи существующего ID другим содержимым.
  Проверена эксклюзивная блокировка одного файлового хранилища.

Chromium использовал настоящие Go handlers и одноразовую PostgreSQL, без
перехвата запросов Playwright: первое открытие передало 7 PNG по HTTP; второе
передало 0 PNG и не отправило за ними запросы CDN. Во всех семи записях повторной
загрузки transferSize=0. Голограмма, внешний SVG-значок профиля и чтение Canvas
работают; счётчик графических обращений к Cosmic равен нулю.

Cosmic Linux уменьшился с 29 835 426 до 16 097 442 байт: на 13 737 984 байт,
46.05%. Это размер отдельного binary, а не утверждение о снижении суммарной RAM
или размера полного набора служб. Asset pack: 283 ресурса, ZIP 8 166 453 байта,
включая JSON-описания. Полные размеры/хеши находятся в build manifest и SHA256SUMS.

Пакеты проверены на checksum mismatch, неполную загрузку, traversal, недопустимые
пути/типы и незаявленные файлы. Подтверждены offline restart, неизменяемые URL,
HEAD/304/Range, разные ETag для SVG/gzip, независимое обновление одной картинки,
сохранение старых URL и откат выбранного пакета после рестарта. Private media
проходят новую ACL-проверку даже перед 304; отказ Cosmic и прямой обход не
раскрывают изображения.

Windows-файлы кросс-компилированы и проверены как PE amd64; выполнение на Windows
и SCM в этой Linux-среде не проверялось. Рабочая PostgreSQL и реальные службы
владельца не изменялись. Сборка/публикация релиза не равна обновлению его сервера.
