# Astra Journey 0.31.5 — рабочая сводка MATRIX × STUDIO

Баланс, местоположение и игровое время собраны в одну панель. Кнопки перестановки, изменения ширины и удаления карточек доступны через «Настроить пространство».

- Таблица флота выделяет состояние кораблей. Карточка корабля показывает остаток топлива и заполнение трюма. Перелёты, добыча и исследования видны в сводке операций, где задачи выбранного корабля идут первыми.
- Рынок станции показывает наличие, цену покупки и цену продажи. Предложения игроков вынесены в отдельное представление. «Открыть рынок» ведёт на соответствующую вкладку.
- На узких экранах карточки выстраиваются в одну колонку, а подписи и цены остаются читаемыми. Сохранённые раскладки подходят для обновлённого интерфейса.

## Установка поверх 0.31.4

1. Скачайте файлы релиза и выполните `sha256sum -c SHA256SUMS` из каталога загрузки.
2. Запишите текущую ревизию из `/web/api/v1/health/ready`. Для ручной установки используйте `sync_enabled = false` в секции `[web]` действующего TOML. Остановите службу Web.
3. Запустите существующий Web 0.31.1 с тем же `CONFIG_FILE` и аргументом `--install-pack /path/to/astra-journey-web-REVISION.zip`. Затем запустите Web штатно.
4. Сверьте поле `revision` в `/web/api/v1/health/ready` с полем `revision` в `astra-journey-web.json`.

Комплект обновляет только Web-пакет. Используются действующие Cosmic 0.31.3, CDN и PostgreSQL. Номер версии игры в шапке берётся из Cosmic.

Для отката остановите Web, запустите его с тем же конфигом и аргументом `--activate <предыдущая-ревизия>`, затем запустите службу штатно.
