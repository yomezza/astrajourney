# Исправление блокировки запуска · 0.30.3

18 ноября 2026 года. Владелец сообщил о зависании на «Подключение к серверу»
после установки Web-пакета 0.30.2, затем предоставил ошибку браузера:
`Uncaught SyntaxError: Identifier 'snapshot' has already been declared
(at index.js:528:11)`. Проблемная Web revision:
`72866b1a608b457c88850f29a74072e4ba1235342a1e0086dfea51c2071338da`.

**Статус: hotfix 0.30.3 опубликован** в продолжение ранее порученного
публичного выпуска. [Релиз](https://github.com/yomezza/astrajourney/releases/tag/v0.30.3),
[успешный workflow](https://github.com/yomezza/astrajourney/actions/runs/44263460655).
Main и тег отправлены в origin. Новых локальных
функциональных/браузерных и нагрузочных тестов не запускали по ограничению
владельца.

## Причина и изменение

В `web/features/administration/galaxies/index.js` коммит `cdd0b19` добавил
`const snapshot` для кеша каталога в той же функции, где уже существовал
`let snapshot` для токена предпросмотра. Модуль входит в статический граф
импортов bootstrap, поэтому синтаксическая ошибка блокировала запуск всего
приложения до авторизации. Статусы HTTP 200 у JavaScript не означали,
что браузер смог разобрать и выполнить модули.

Локальный каталог теперь называется `catalogSnapshot` во всех четырёх
переходах (выбор карточки, создание/переход к черновику, сброс).
Переменная предпросмотра сохранена отдельно. Настройки подключения,
таймауты локализации, БД и NATS не меняли для устранения этой ошибки.

В ходе диагностики прочитан уже состоявшийся GitHub Actions run
`44248984396` для 0.30.2: browser job завершился по таймауту 15 минут,
аннотации содержат ожидание `__testReady`. Это прежний автоматический run,
а не новый локальный тест. Ранее успешным объявлялся только workflow
публикации 0.30.2, который проверяет целостность файлов, не JavaScript-синтаксис.

## Обновление установки

Полный комплект: заменить пять Linux-бинарников, установить
`[web].release_tag='v0.30.3'`, запустить Cosmic, затем Planet/Chat/CDN/Web,
дождаться активации пакета и обновить страницу игры. Синтаксическое исправление
находится в Web-пакете; для срочного восстановления интерфейса он совместим
и с прежними API 0.30.2 (`astra-api-v1`). Графику CDN заново не устанавливать.

## Подтверждение публикации

Release workflow завершился с `WORKFLOW_RUN_CONCLUSION_SUCCESS`. Публичная
страница релиза и все 17 записей файлов поставки доступны. Публично скачанные
Web/graphics JSON и build manifest совпали с локальными. Дополнительно скачан
опубликованный Web ZIP: SHA256
`bcb1636a260e0a9e9d45ccc48608ed28218463f86af0cd0c2011f1bbf9485bd9`
совпал с индексом. В исходнике редактора внутри опубликованного ZIP есть
`const catalogSnapshot` и отсутствует конфликтующий `const snapshot` каталога.
Это подтверждение артефакта, а не выполнение браузерного теста. Доказательства
публикации сохранены в `dist/release-v0.30.3/`.

Срочный путь восстановления не требует перезапуска остальных служб:
для Web 0.30.2 оставить остальные настройки, задать `sync_enabled=true`,
`release_tag='v0.30.3'`, перезапустить Web, дождаться установки нового пакета
и обновить страницу. Полный переход на пять бинарников 0.30.3 также обновит
общую версию в БД при запуске Cosmic.

Следующий шаг: владельцу активировать новый Web-пакет на своей установке
и подтвердить открытие интерфейса; удалённое обновление его сервера не выполнялось.
