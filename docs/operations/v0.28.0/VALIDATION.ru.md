# Проверки 0.28.0

Производственные исходники сборок — коммит `5f22438` (полный SHA в build manifest).
Последующие изменения до релизного тега затрагивают только тесты, отчёт и артефакты.
Рабочая база владельца не использовалась.

- `npm test --prefix tests/ui`: **79 passed**, без JS exceptions и неожиданных API.
- Go-пакеты вне `internal/server/integration`: `go test … -count=1 -timeout=8m` — PASS.
- Полный набор из 174 интеграционных Go-тестов распределён между четырьмя
  отдельными одноразовыми `_test` базами. После исправления и повторного запуска
  шести устаревших проверок: **146 passed, 28 skipped**, нерешённых ошибок нет.
  Точные результаты и дополнительные живые браузерные проверки — в
  [validation.json](validation.json). Пропуски относятся к отдельно включаемым
  браузерным, NATS, Docker backup и нагрузочным сценариям.
- `RUN_NAMING_BROWSER=1 … TestNamingProductionBrowser280` — PASS: исчезновение
  кнопки системы после rename/reload, отдельное окно, характеристики планет,
  одноразовое меню планеты, отсутствие rename полей, реальные 409/403, без JS ошибок.
- `RUN_CATALOG_BROWSER=1 … TestCatalogProductionBrowser` — PASS на настоящих
  Go handlers/PostgreSQL: исследования, доступные объекты, колонии, взносы,
  возвраты, поверхность, фильтры/выбор, RU/EN, широкое и узкое окно.
- `go test -race ./internal/server/integration …`: PASS для конкурентного
  переименования, прав системы/планеты, холодного кэша и открытия без инициализации.
- `go vet ./...` — PASS.
- Миграция настоящей установки, созданной опубликованным Linux Cosmic 0.27.0:
  [upgrade-result.json](upgrade-result.json). Хеши users, ships, star_systems,
  system_planets, aj_discovery_objects, aj_discovery_name_history, warehouses
  совпали; пользовательское имя станции и потраченное право сохранены,
  4500 природных полей получили постоянные UUID, повторный запуск стабилен.
- Проверены пустая галактика и её расширение, новые галактики с изменёнными
  словарями, словарь станций из одного сочетания, 10 000 уникальных имён при
  исчерпании словаря, сохранение выключенных слов при restart, отсутствие
  скрытого fallback. Старые коллизии и неактивные станции проверены отдельно.
- География чистого `origin/main` и текущего генератора совпала после исключения
  только названий/версии именования. Старые хеши планетарной географии сохранены.
- Все шесть amd64 файлов собраны Go 1.26.0 с CGO=0; проверены PE/ELF и manifest.
  Релизные Linux Cosmic, Planet и Chat реально запущены на тестовой базе,
  Planet/Chat вернули `ready`, все службы — 0.28.0.
- `sha256sum -c downloads/SHA256SUMS` — PASS для прежних и новых файлов.
  Windows-файлы собраны и проверены как PE amd64, **в Windows не запускались**.

Общий первый последовательный прогон был неуспешен и достиг лимита 15 минут;
он не представлен как зелёный результат. Итоговое покрытие получено разбиением
набора и успешными повторными проверками исправленных сценариев.

Исправления старых проверок: верный доменный адрес chat_outbox, допустимость
выбора плана PostgreSQL с отдельной проверкой пригодности GIN, ожидание закрытия
backend, проверка приватных **полей**, маршрутизация повторной DDL-миграции через
`dblayout`, актуальный 32px pixel-art pack. Производственная логика Chat,
география и движение ради этих проверок не изменялись.
