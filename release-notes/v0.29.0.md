# Astra Journey 0.29.0

Добавлена четвёртая Go-служба **AstraJourney CDN** для Linux amd64 и Windows amd64.
Она хранит и раздаёт графику из файловой системы, без PostgreSQL. Из Cosmic
удалены все встроенные изображения и текстуры; источники сохранены в `assets/game`.

- Готовые пакеты автоматически загружаются из GitHub Releases. CDN создаёт
  каталоги, проверяет архив/манифест/файлы и сохраняет прежние версии для отката.
- URL содержат хеш отдельного файла. Браузерный кэш сохраняет неизменившиеся
  текстуры между страницами и выпусками; SVG поддерживают gzip, HTTP — HEAD/304/Range.
- Совместимый новый набор графики применяется через маленький манифест страницы,
  без пересборки Cosmic. Уже открытая страница сохраняет выбранный набор.
- Нативная поддержка NATS: отдельный профиль/ACL CDN, readiness/change hints,
  reconnect и работа публичной графики при отказе брокера.
- Защищённые изображения руководства передаются CDN с актуальной проверкой прав
  в Cosmic. Загрузка/нормализация и durable receipts перенесены в файловую службу.
- CDN может быть входным HTTP-шлюзом игры: дополнительные страницы/API передаются
  в Cosmic, графические байты обходят его процесс. В окне «Службы» добавлена CDN.
- Миграция 290 один раз обновляет отображаемую версию игры в единственной записи БД;
  последующие ручные изменения версии сохраняются при обычном перезапуске.

**Обновление требует настройки CDN и адреса входа.** По умолчанию игра открывается
на `http://127.0.0.1:8083`, Cosmic остаётся приватным на `127.0.0.1:8080`.
Обновите public_origin и allowed_origins Planet/Chat. Если использовался
GUIDE_MEDIA_DIR, выполните копирующий импорт перед переключением. Сохраните
прежние конфигурацию, схему БД, файлы руководства и журнал чата для отката.

[Установка, автоматическая синхронизация, кэш, NATS и перенос файлов](../docs/operations/cdn.ru.md).

Поставка: восемь исполняемых файлов четырёх служб, отдельный общий asset pack,
`astra-journey-assets.json`, build manifest и SHA256SUMS. Ранее опубликованные
выпуски и их артефакты сохранены.
