# Обновление MATRIX × STUDIO 0.31.2 для Linux amd64

В комплект входят Cosmic (`astra-journey-v0.31.2-linux-amd64`) и ZIP пакета Web (`astra-journey-web-<revision>.zip`). Для установки ZIP подходит Web 0.31.1. Графический пакет CDN и бинарники Web, CDN, Planet и Chat в этот комплект не входят.

1. Из распакованного комплекта запустите `sha256sum -c SHA256SUMS`. Сохраните резервную копию PostgreSQL, прежний бинарник Cosmic и ревизию Web из `/web/api/v1/health/ready`.
2. Остановите Web. На время миграции остановите Chat и Planet, если они запущены, затем Cosmic. Замените бинарник Cosmic, сохранив путь, владельца и исполняемые права. Запустите Cosmic с прежним `CONFIG_FILE` и дождитесь успешной миграции. Затем запустите Planet и Chat, если они используются.
3. В действующем TOML задайте `[web]` → `sync_enabled = false`. Установите ZIP текущим Web-бинарником от имени пользователя службы, с прежним каталогом хранения и тем же `CONFIG_FILE`:

   ```sh
   CONFIG_FILE=/etc/astra-journey/shared.toml /path/to/astra-journey-web --install-pack /path/to/astra-journey-web-REVISION.zip
   ```

4. Запустите Web. Проверьте `/api/health`, `/web/api/v1/health/ready`, вход и сохранение пространства после перезагрузки. Откройте карту, чат и уведомления в той же сессии.

Если нужно вернуть прежний интерфейс, остановите Web, с тем же конфигом выполните `astra-journey-web --activate <предыдущая-ревизия>` и запустите Web. Перед откатом серверной части проверьте журнал миграции и используйте согласованную резервную копию, если требуется восстановление базы.
