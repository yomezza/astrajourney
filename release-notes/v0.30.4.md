# Astra Journey Web 0.30.4

Отдельный выпуск Web-службы и интерфейса. Linux amd64.

Обновлено оформление галактической карты и карты звёздной системы:

- Тёмное навигационное поле с мягкой глубиной фона и тонкой сеткой.
- Более читаемые гиперкоридоры и орбиты, выделение выбранной системы
  с контрастным кольцом и визиром, мягкое выделение объектов системы.
- Новое оформление верхней панели, выбора галактики/системы, вкладок
  инспектора, карточек флота и объектов, легенды и масштаба.
- Меню отображения с ясным состоянием включённых фильтров.
- Адаптация к ширине самого окна: перенос панели управления и расположение
  инспектора под картой в узких окнах. Панель по-прежнему можно скрыть.

Обработчики поиска, выбора, перетаскивания и масштаба, расчёт маршрутов,
промежуточные точки, заметки, закладки, фильтры, действия объектов и кораблей,
контекстные меню и переход на поверхность сохранены. Новая сетка декоративна
и не участвует в расчёте координат или определении нажатий. Новых текстур,
библиотек и фоновых анимаций нет.

## Обновление только Web

Сохраните остальные параметры конфигурации и каталог Web. Замените только
`astra-journey-web-v0.30.4-linux-amd64`. В существующей секции `[web]`:

```toml
sync_enabled = true
release_tag = 'v0.30.4'
```

Перезапустите Web, дождитесь активации пакета и обновите страницу браузера.
При ручной установке используйте ZIP с именем из `astra-journey-web.json`
и команду `--install-pack`.

**Cosmic, Planet, Chat и CDN остаются на 0.30.3.** Совместимый API-контракт
`astra-api-v1` сохранён. Пакет интерфейса также можно установить на Web
0.30.3, закрепив новый `release_tag`. БД, отображаемая версия игры из БД,
схемы и графический пак не меняются. Web сообщает собственную версию 0.30.4.

Релиз содержит только Web ELF, build manifest, Web ZIP/JSON, пример конфига
Web и SHA256SUMS. Сборщик поддерживает `--service web` без сборки графики;
workflow публикует выбранный состав. Выпуск не заменяет общий GitHub Latest:
CDN продолжает находить графику в последнем полном релизе. Web использует
явно указанный тег `v0.30.4`.

По прежней просьбе владельца локальные функциональные и нагрузочные тесты
не запускались. Компиляция, подготовка пакета и проверка целостности поставки
выполняются обычным сборщиком и release workflow.
