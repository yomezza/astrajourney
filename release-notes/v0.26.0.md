# Astra Journey 0.26.0 — системы и планеты в таблицах

Общий JSONB мира заменён таблицами галактик, систем, планет, регионов и
гиперкоридоров. Характеристики объектов остаются в небольших JSONB `details`;
координаты, названия, типы и параметры расчётов — типизированные колонки.
Системы секционируются **PARTITION BY LIST(galaxy_id)**. Новая галактика получает
секцию автоматически; изменение её названия не меняет секцию.

У систем и планет постоянные UUID. Переименование из UI передаёт UUID,
проверяет прежние права и изменяет только нужную строку и ревизию. Старые
числовые ID и ссылки кораблей/колоний/заданий сохранены. История переименований
сохраняется; новые квитанции содержат UUID. Поддерживается прежний формат запросов.

**Перед обновлением:** сделайте согласованный backup БД и файлов, остановите
старые службы, сохраните TOML, имя схемы и erasure journal. Новый Cosmic можно
сначала запустить с `--check-universe`: режим читает БД без записи/миграций.
Затем запустите новый Cosmic для переноса, после него Planet и при необходимости
Chat. Миграция выполняется в одной транзакции со сверкой данных и FK;
некорректные ссылки приводят к rollback, без автоматической правки имущества.

Старый `galaxies.data` сохраняется как архив и защищён от записи. Старый бинарник
после cutover не является способом отката: требуется восстановление backup до
миграции. Рабочие данные владельца в облачной среде не изменялись.

Проверены PostgreSQL-миграция/rollback, UUID и точечное переименование,
конкурентный снимок, read-only CLI, кэш, портал/навигация/старые обновления,
новые галактики до 50000 систем, реальный браузер и Planet. Windows EXE
кросс-компиляция, без непосредственного запуска на Windows.

Сборки трёх служб: **Linux amd64 и Windows amd64**. Предыдущие файлы downloads
сохранены. Планетарная схема остаётся 10; частота SQL-проверок WASD не менялась.
