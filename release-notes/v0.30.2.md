# Astra Journey 0.30.2

**Известная проблема запуска:** Web-пакет этого выпуска содержит конфликт
объявлений `snapshot`, блокирующий общий bootstrap. Используйте исправленный
[выпуск 0.30.3](https://github.com/yomezza/astrajourney/releases/tag/v0.30.3).

Linux amd64. Исправлены повторные загрузчики модулей и всплески запросов
чата, уменьшена повторная работа Cosmic, Web/CDN и браузера.

## Исправления модулей и чата

- Фоновое обновление открытого модуля не показывает заставку и не перехватывает
  фокус. Загрузчик остаётся при первоначальном открытии и подготовке ресурсов.
  Карта системы не переоткрывает себя на каждом обновлении и не обновляется
  под открытой поверхностью планеты. Повторные обновления объединяются,
  устаревшие отменяются при закрытии/новом открытии.
- Чат объединяет одинаковые GET и повторные сигналы обновления, распределяет
  запросы по времени и учитывает Retry-After при 429/503. Закрытый чат не
  перечитывает историю. JSON сжимается; неизменившиеся ответы поддерживают
  ETag/304 после свежей авторизации, с сохранением `no-store`.
- При всплеске сервер чата допускает до 64 работающих и 64 ожидающих HTTP-
  запросов; ожидание ограничено 250 мс. Постоянная перегрузка получает 429.
  WebSocket-команды автоматически повторно не отправляются.
- Outbox читает ограниченные диапазоны новых ID и временного overlap с планом
  на каждый вызов, сохраняя обработку поздних COMMIT, проверку прав и сверку
  состояния. Режимы a1/b1 и настройки брокера автоматически не меняются.

## Оптимизация служб

- Cosmic загружает собственный флот одним запросом. 20 запросов представления
  терминала отправляются пакетом на одном соединении; число SQL-операторов
  при этом сохраняется. Время активности записывается не чаще раза в 30 секунд.
- Навигационные ядра и порталы повторно используются для неизменившегося
  снимка мира. Расчёт маршрутов использует меньше отдельных массивов памяти,
  сохраняя порядок обхода и выбор пути.
- Раздел «Галактики» использует кеш мира и статистики генерации. Имущество
  и обязательства станций учитываются свежим запросом. Выбор карточки галактики
  в редакторе больше не перечитывает весь каталог.
- Cosmic и Planet используют общий механизм gzip-сжатия JSON с повторным
  использованием writer. WebSocket Upgrade обходит сжатие.
- Web/CDN заранее готовят gzip и ETag публичного каталога. Параллельные
  обращения Web разделяют одну загрузку из CDN; HTTP и запись ответа не
  удерживают общий замок. Сохраняются TTL и инвалидация сигналами NATS.
- Web кеширует подготовленные HTML/CSS/JS/JSON: до 256 записей и 16 МиБ
  удерживаемых буферов. Старые ревизии участвуют в том же бюджете; пакеты
  на диске автоматически не удаляются. Поддерживаются HEAD, 304 и Range.
- Скрытая вкладка приостанавливает регулярный опрос терминала, при возвращении
  данные обновляются. Серверные действия, чат и планетарное соединение работают
  независимо. Модули, которым не нужна карта, больше не ждут её загрузки.
- При подготовке грунта планеты три ближайшие точки материалов выбираются
  без сортировки всего списка для каждой ячейки; формулы смешивания сохранены.
- Диагностика учитывает SQL-операторы в batch и новый счётчик `sql_batches`.

## Обновление с 0.30.0 / подготовленной 0.30.1

Сохраните конфиг, прежний `database.schema`, каталоги Web/CDN, service token
и журнал чата. Остановите службы и сделайте резервную копию БД. Замените пять
бинарников Linux amd64. Первым запустите Cosmic, затем Planet, Chat, CDN и Web.
Порты, роли БД, пулы соединений и настройки NATS менять не требуется.

Миграция 302 один раз обновляет общую отображаемую версию в `game_release`
до **0.30.2**. Последующие ручные изменения версии сохраняются при обычных
перезапусках. Новых игровых таблиц и индексов в этом выпуске нет. Изменения
не применялись к рабочей БД при подготовке релиза.

**Новый Web-пакет обязателен.** Если задан `[web].release_tag`, установите
`'v0.30.2'`. При `sync_enabled=true` Web получает пакет из этого релиза.
Для ручной установки скачайте ZIP с именем из `astra-journey-web.json`:

```sh
CONFIG_FILE=/etc/astra-journey/config.toml ./astra-journey-web-v0.30.2-linux-amd64 --install-pack /path/to/astra-journey-web-REVISION.zip
```

После активации обновите страницу игры. **Графический пак прежний**:
повторно устанавливать его на существующем CDN не нужно. Он включён
в релиз для новых установок. Старые бинарники и пакеты сохранены.

## Состав и границы проверки

Пять статических Linux amd64 ELF, build manifest с исходным коммитом,
Web/graphics ZIP и JSON-индексы, шесть TOML-примеров и SHA256SUMS.
Node.js и Python не требуются для работы служб. Windows-сборок нет.

По просьбе владельца локальные функциональные, браузерные и нагрузочные
тесты при подготовке не запускались. Сборщик и workflow публикации проверяют
формат и целостность файлов поставки. Проценты ускорения и новая вместимость
сервера после изменений не измерены; прежние результаты 100-player прогона
0.30.0 не являются проверкой этого выпуска.
