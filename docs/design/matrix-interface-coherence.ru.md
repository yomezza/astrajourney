# ТЗ на согласование интерфейса MATRIX × STUDIO

Рабочая версия для сравнения — Web 0.31.5. Приоритет у сценариев, в которых пилот переключается между картой, рабочим пространством и рынком во время одной сессии.

| Проблема | Что изменить | Как принять работу |
| --- | --- | --- |
| Боковая панель повторно загружает уже открытый модуль, а каталог использует другой путь. Карта системы и карта галактики делят одно окно | Соединить точки входа общей навигацией. Для обычного открытого окна использовать переключение, для карт — явный переход в выбранный режим. В каталоге различать переключение окна и переход по карте | Открыть карту текущей системы и перейти к галактике через каталог. Повторно открыть рынок с боковой панели и проверить сохранность выбранной вкладки и черновика |
| Панель окон создаёт кнопки заново при каждом обновлении заголовка. При закрытии активного окна теряется признак текущего окна | Сохранить узлы переключателей, отмечать текущее окно, после его закрытия выбирать последнее доступное | Переключить окна с клавиатуры, обновить заголовок, закрыть верхнее окно и проверить отметку и фокус |
| При задержке рынка вкладки перестраиваются вместе с панелью. Клавиатурный фокус теряется после ответа | Дать рынку постоянную панель вкладок и отдельную область данных. Разложить вкладки адаптивной сеткой, выделить текущую вкладку и показать ожидание ответа | Задержать ответ глобального рынка, перейти на соседнюю вкладку и проверить фокус, связь вкладки с панелью и игнорирование устаревшего ответа |
| Сводка и экран торговли рисуют таблицы разными компонентами. Общий CSS выравнивает колонки по номеру | Переиспользовать семантический компонент таблицы. В сводке, рынке и перевозках задать выравнивание по типу данных и единый стиль заголовков. Широкие таблицы прокручивать внутри собственной области | Сверить имена, статусы, количества и цены на 320, 768 и 1440 px. Проверить доступ к последней колонке с клавиатуры |
| На снимке рынка при 320 px правый край цены продажи уходит за границу. При совпадении названий станция и система выводятся дважды | Уменьшить боковые отступы таблицы цен на узком экране и показывать совпадающее название один раз | Открыть рынок стартовой станции в готовом Web-пакете при 320 px и сверить видимость всех четырёх колонок и заголовок места |

Критерии совместимости — сохранённые раскладки, русский и английский языки, исходные компоненты чата и уведомлений, переходы в планетарный режим и действующие игровые API. Сценарии проверяются локально.
