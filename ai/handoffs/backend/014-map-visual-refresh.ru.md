# Оформление карт · отдельный выпуск Web 0.30.4

18 ноября 2026 года. Владелец поручил модернизировать галактическую карту
и карту системы с сохранением функционала; выпускать только Web, если
другие службы не затронуты. Ветка `feature/map-visual-refresh`.

**Статус: отдельный Web-релиз опубликован.**
[Web 0.30.4](https://github.com/yomezza/astrajourney/releases/tag/v0.30.4),
[успешная публикация](https://github.com/yomezza/astrajourney/actions/runs/44268321334).
Коммит поставки и тег: `a69359e`; исходники интегрированы в main.

## Реализация

- `web/styles/maps.css`: отдельное оформление навигационной консоли,
  панели управления, инспектора и вкладок, фильтров, объектов и флота,
  легенды/масштаба. Стили ограничены модулем карты. Перенос элементов зависит
  от ширины окна модуля, в узких окнах инспектор располагается под картой.
- `web/index.html`: подключение нового CSS после прежних стилей.
- `web/features/maps/galaxy.js`: декоративная сетка, читаемость орбит и
  гиперкоридоров, визир выбранной системы и мягкое выделение объектов.
  Сетка не меняет координаты объектов и hit testing. Существующие обработчики
  поиска, перетаскивания, масштаба, фильтров, маршрутов, меню и переходов
  сохранены. Новые изображения, внешние зависимости и анимационные циклы
  не добавлены.
- Web имеет версию 0.30.4; Cosmic/Planet/Chat/CDN остаются 0.30.3.
  Общая версия игры в БД не менялась, миграций нет, API astra-api-v1 прежний.
- `scripts/build-release.py --service web` теперь действительно пропускает
  подготовку/обновление графического пакета и его индекса.
- `.github/workflows/release.yml` определяет состав по build manifest.
  Отдельный Web-выпуск публикует только Web и его пакет, без CDN/других служб.
  `--latest=false` сохраняет общий Latest на полном 0.30.3, чтобы работающий
  CDN не искал отсутствующий graphics JSON в отдельном Web-релизе.
  Полный состав для будущих общих выпусков сохранён.

## Установка

Заменить только Web-бинарник, в существующей секции `[web]` указать
`sync_enabled=true`, `release_tag='v0.30.4'`, перезапустить Web и обновить
страницу после активации пакета. Остальные службы, БД и CDN не обновлять.
Сам Web-пакет также совместим с Web/API 0.30.3.

Публично подтверждены ровно шесть файлов: Web ELF, manifest, Web ZIP/JSON,
web.example.toml, SHA256SUMS. Скачанные индекс и manifest совпали с локальными;
в manifest единственная служба `web`. GitHub `/releases/latest` по-прежнему
перенаправляет на v0.30.3. Доказательства сохранены в `dist/release-v0.30.4/`.

Следующий шаг: владельцу установить Web-пакет/бинарник и оценить оформление
на своей установке. Удалённое обновление его служб не выполнялось.
