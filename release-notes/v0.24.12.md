# Cosmosimulator 0.24.12 — NATS без TLS и общий config.toml

Cosmic, Planet и Chat теперь поддерживают обычный NATS `nats://host:port`
с `username` и `password` в TOML либо NATS_USERNAME / NATS_PASSWORD в ENV.
Для этого режима не нужны CA и password_file. Прежний TLS режим и password_file
сохранены; смешанный список nats:// и tls:// отвергается, TLS не откатывается к plaintext.

Один config.toml может содержать общие NATS параметры и отдельные профили
`[nats.cosmos]`, `[nats.planet]`, `[nats.chat]`. Каждая служба выбирает свои
учётные данные. Старые отдельные конфиги с плоским `[nats]` продолжают работать.
NATS по умолчанию отключён; у Chat для подключения выбирается dispatcher_mode='b1'.

В релизе и downloads: все три службы для Windows amd64 и Linux amd64,
SHA256SUMS, build.json и готовый shared.example.toml. Linux сборки статические.

Проверены реальные NATS user/password, неверный пароль, reconnect, TLS regression
и три отдельные native -race службы с одним общим конфигом и PostgreSQL.
Рабочие службы и брокер владельца не менялись; игровой протокол и SQL ACL сохранены.
