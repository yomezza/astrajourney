# Cosmosimulator 0.24.3 · работа служб и команд на HTTP в локальной сети

Исправлена ошибка `crypto.randomUUID is not a function` при открытии терминала
по HTTP с сетевым IP. Чат, создание высадки, переходы между секторами и
возвращение в космос используют общий генератор UUID v4 на
`crypto.getRandomValues`. Криптографическая случайность и строгая CSP сохранены.

Внутренние health-запросы и HTTP/WebSocket gateway обращаются к настроенным
адресам служб напрямую, независимо от системного HTTP_PROXY. В статусе служб
появилась подсказка о включении Chat в окружении Cosmic.

Для Chat, слушающего `192.168.111.44:8082`, в окружении Cosmic необходимо задать
`CHAT_ENABLED=true` и `CHAT_INTERNAL_URL=http://192.168.111.44:8082`, затем
перезапустить именно этот процесс. Переменная `$env:` в другой консоли не
обновляет окружение действующей Windows-службы. Полный пример и команды
диагностики находятся в [инструкции Chat](../docs/chat-service/README.ru.md).

Проверено: UUID в браузере на небезопасном HTTP IP origin при строгой CSP,
граф зависимостей ES-модулей, затронутые Go-пакеты и сборка трёх Windows EXE.
Подключение к конкретной LAN пользователя не проверялось. Причину стороннего
inline-скрипта и индивидуального переподключения без логов установить нельзя.
Новых миграций БД нет. Предыдущие Windows-сборки сохранены.
