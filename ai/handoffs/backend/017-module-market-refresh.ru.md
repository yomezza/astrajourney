# Стабильный рынок корабельных модулей · Web 0.31.1

19 ноября 2026. Ветка `fix/module-market-refresh` от main `07d3ce3`.
Поручение: устранить постоянное обновление вкладки «Модули корабля».

**Статус: исправлено в исходниках, готовится выпуск только Web.**

## Причина и исправление

`markets/index.js:drawMarket` сбрасывал всё содержимое окна до асинхронного
GET `ship/modules`. Каждое фоновое обновление оставляло вкладку без карточек
на время ответа, заново создавало фильтры и теряло DOM-состояние.

Теперь оболочка открытой вкладки переиспользуется. `markets/modules.js`
сохраняет контролы и карточки по catalog_id, обновляет текст, остатки, цену
и доступность кнопки на месте. Изменение набора станций обновляет список
только по факту изменения; обычный опрос не закрывает фильтр и не сбрасывает
фокус. Карточка покупки берёт актуальные корабль/станцию/цену из последнего
принятого ответа. Смена вкладки, языка и сессии сохраняет прежние защиты
RequestScope; module-фильтры очищаются при выходе из сессии.

Меняются только Web-исходники и версия Web 0.31.1. Cosmic остаётся 0.31.0,
Planet/Chat/CDN — 0.30.3. Миграций/изменений API/графики нет.
